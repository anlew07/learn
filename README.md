# 同时穿越：末日模拟器

> 多世界并行的文字末日模拟器 · TapTap H5 · **当前处于设计阶段，尚未开始编写游戏代码**

**核心概念：** 同一个灵魂同时穿越多个末日世界。每个分身自主生存、成长、冒险和尝试拯救自己的世界。玩家通过有限的灵魂行动点进行关键干预，并让多个自己分享记忆、资源和战斗力量。

**宣传核心句：** 一个我拯救不了末日，那就两个我、三个我一起上。

## 项目现状

- 设计基线：V1（2026-11-12）。核心框架已梳理，**不代表已经通过实机、概率或平衡测试**。
- 首局：灵灾 + 尸潮双世界；第三局解锁兽潮三世界。
- 目标局长：教学局约 15–25 分钟，普通局约 30–60 分钟（1×）；支持 1×/2×/4× 与随时暂停。
- 第一版：原生 HTML/CSS/JavaScript，竖屏文字 UI；开发时模块化，发布时可合并打包。
- 核心体验：世界自动演化、有限干预、事件与经历分支、万我同源。
- 暂不做：复杂手动战斗、联网账号、排行榜、地图探索画面、装备词条与大量独立生存数值。

~~~

**内容状态：** 【确定】指架构原则；【暂定】指数值或未测试方案；【待设计】指仅有接口尚未填充。不要把故事示例当成一定发生的固定剧情。

**更新原则：** 先修改对应权威文档，再更新相关内容包，最后记录变更；不要把同一规则复制成多个互相矛盾的版本。当前可以进行破坏性设计修改，尚不承诺早期原型存档兼容。

原学习资料已从当前项目删除，当前 main 分支已从游戏项目的新根提交开始；仓库外旧克隆或平台缓存不属于当前主分支历史。
