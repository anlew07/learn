# 三世界联动内容包 01 · 三人之力、回响与独立结局

**版本 V0.1 · 2026-11-12 · 内容设计稿，尚未写游戏代码/数值测试**

## 0. 解锁与世界数量

- 第一局**同时运行灵灾+尸潮**，已有被动记忆与跨世界P/D援助。
- 第二局保持双世界，正式解锁一次性重大/终局战斗的二人之力。
- **第三局**开放兽潮，三个世界同一个游戏日并行；三人之力随该模式解锁。新开局才确定世界数量，不能中途追加兽潮分身。
- 只存在当前实际running世界之间的普通灵魂援助/融合；已拯救世界可以留下回响，但不能作为正在战斗的分身。
- 第三局解锁三世界是本包的首版方案；未来永久解锁界面可提供再次游玩双世界的选项，但不修改正在运行的世界集合。

## 1. 三世界共用时钟与事件结算

灵灾、尸潮、兽潮分别只有每日一个主要行动；各世界在固定独立随机流下自主决定行动。三个世界的事件队列独立，彼此不覆盖。全局AP、灵魂与融合冷却是唯一共享资源。

同一天出现多个事件时：每世界仍最多一个待处理重大事件，界面可按紧急度排序。三个世界当日行动与结局完成后，在**统一记忆广播阶段**结算重大经历；日终按全局顺序一次提交保存。来源与接收世界在广播时必须仍running。被动共享给的经验不能修改本日已结算战斗或触发无限共享。

## 2. 三世界记忆传播

来源规则仍是每世界最多成功广播3次、相邻广播间隔5个完整游戏日，同一 memoryKey 只广播一次。**每个当前running的接收世界都可以获得该来源本次经验+5（暂定）**。

两个不同来源同日广播给第三世界，则第三世界可以分别合法获得两次XP+5；两条记录必须具备不同 broadcastId，不得重发同一来源。总入账最多由当日另外两个running来源决定；**暂不新增额外的每日接收上限**，先测试 +10 是否让第三局成长过快。

三人世界共享仅传通用成长/适用感悟，不直接互换灵石、废土零件、进化结晶，也不复制各世界境界名、功法或剧情标记。

## 3. 三人之力（一次指定战斗）

**ID：`soul.fusion.three`**。只在至少三个世界实际running，且有一个确定的、允许融合的重大或终局战斗时可选。

| 字段 | 首版条件/效果 |
| --- | --- |
| 承载世界 | 当前战斗所处的running世界，必须符合事件或终局的全部非战斗前置条件 |
| 两个提供世界 | 与承载者不同、running、各实际Lv≥2、未闭关、无禁止借力状态 |
| 本次战斗加成 | 承载者有效战斗等级+2，不永久升级 |
| 费用 | AP2、灵魂强度2；主动消费后必须至少剩1魂 |
| 共用冷却 | 20个**完整游戏日**，第t日发动后t+21日才可再次使用二人/三人之力 |
| 提供者代价 | 两个来源各在t+1、t+2、t+3日可缩放自动XP/R正收益-30% |
| 事件费用 | 该次融合AP替代普通重大事件AP费用，不再重复扣 |
| 与本地强化 | 同一次战斗内本地强化和二/三人之力互斥 |

**战斗公式：** 有效等级 = 承载者实际Lv + 本次融合(+2) - 当前状态惩罚。基础资格（实际等级、P、材料、已调查线索、世界存活）不能由+2替代；若+2后仍不足战胜对手，则拒绝并且不扣AP/魂。

例如兽潮实际Lv3、狂化兽王要求Lv5，且P100、R14、已找到变异源、另外两分身均满足资格，才能选择三人之力提前讨伐。**不过兽潮仍有两次非随机压制+实际Lv4的独立通关路线**，三人融合不是强制胜利条件。

灵灾的普通灵脉封印不需要Boss战，不能对该条件型终局发动三人之力。

## 4. 二人/三人之力如何退化和切换？

- 在三世界局里也允许二人之力，要求至少两个running世界；如果一次战斗只差1战力，优先提示成本较低的二人之力。
- 二人/三人之力**共用一个全局 nextEligibleDay**，不可先用二人然后立即换三人绕过冷却。
- 三世界局有一个世界saved/failed后，三人之力不可使用；若还有两个running世界，仍可发动二人之力（如果已解锁且冷却完成）。
- 只剩一个running世界时两种融合都不可用。该世界仍靠自己的普通成长/调查/资源采集/兽王压制完成主线。
- 失去一个世界不会取消之前合法生效的融合带来的提供者虚弱；每个来源世界的状态按自己是否仍running继续处理。
- 三人融合是在“选择具体战斗”时一次性使用，不能将+2储存给未来第N天，也不能重复作用于当天其它战斗。

## 5. 三世界资源援助与回响

**资源援助**继续使用统一规则：来源R-4、AP-1、魂-1，目标P+12或D-12；必须来源和目标都running、且不是同一世界；按目标共用8个完整游戏日冷却。三世界局**切换来源**不允许绕开同一目标的冷却。

**世界回响：** 仅在世界已saved时创建一次，属于免费一次性全球能力，来源无需再running；每枚回响可选**另一个running世界**为目标：

| 回响 ID | 来源 | 候选效果 |
| --- | --- | --- |
| soul.echo.lingzai | 已成功封印灵灾 | 目标毁灭D-10 |
| soul.echo.zombie | 已成功净化尸潮 | 目标专属资源R+6 |
| soul.echo.beast | 已成功讨伐兽潮 | 目标通用成长XP+8 |

不同来源回响可以在同一目标合法使用，每枚只可用一次；不受普通资源援助的目标冷却限制（回响不是普通援助）。目标结束或本局结束后未消费的回响不折换额外奖励。

**一次性世界结局和灵魂崩溃：** 一个世界 failed 时灵魂强度-2一次；如果魂强度由被动崩溃降至0，剩余running世界统一按全局崩溃结算流程结束本局，不能在归零以后紧急点击回响“复活”。世界saved和failed均停止普通挂机、事件和战潮，未决事件标记作废，不再发重复奖励。

## 6. 三人之力与“战潮模拟”实验模块的关系

新增的[战潮模拟实验包](../combat/01-survivor-waves.md)目前是**可选机制提案，不改变已经确定的战斗等级与融合规则**。

- 多波战斗只是同一场事件/主要行动的展现与有限附加反馈，不生成额外“可融合目标”。
- 三人之力依旧只对**当前指定Boss/精英那一次主战斗**加+2，不能一场多波分别借力扣费多次。
- 构筑的群攻效率/资源收益不能替代P、材料、实际Lv3资格；不会与融合加成硬叠成新的永久等级。
- 若实验未采纳，三人之力所有规则照样成立，三世界仍能完整运行。

## 7. 玩家界面最少新增内容

三世界卡纵向排列；顶部显示全局日期、魂强度、可用AP、当前融合冷却。灵魂页提供“当前可用融合：三人/二人/不可用”与明确理由（闭关、世界已结束、等级不够、冷却、魂强度不足）。

玩家发起三人之力时：
1. 指定兽王/母巢守卫/合法精英事件实例。
2. 看到目标实际Lv、对手要求、两名来源资格、+2后有效等级。
3. 看到AP/魂**扣费前后值**和两个来源未来3日虚弱。
4. 确认后一次性提交战斗、结局、回响与冷却；失败在提交前被拒绝而不扣任何费用。

重要剧情事件与构筑候选不要同时强制弹出；日常继续挂机，信息以摘要和可选详情呈现。

## 8. 状态与幂等合同

SoulLinkState 继续保存：各源广播记录、每目标普通援助冷却、全球融合 nextEligibleDay、所有 echo 实例和已消费状态、用户操作 operationId与结果。每世界保存仅属于该世界的 statusEffects（魂力虚弱、伤势、闭关等）和独立随机状态。

一次融合是单个事务：校验→扣全球AP/魂→结算目标战斗→更新两个来源虚弱→更新全局冷却→判定目标世界结局/回响→保存。保存失败不得出现部分提交；重复操作不重复扣费或发奖。

三世界同日胜负/共享按当前统一结算顺序处理，不靠世界数组顺序分配记忆；世界结束后跳过普通行动与广播。若存在全部三个世界在同一天结束，先完成每个世界合法状态与魂强度扣减，再一次结算整局奖励。

## 9. 设计验收用例（尚未执行）

1. 第1局灵灾+尸潮，兽潮状态不生成，也不能三人之力。
2. 第2局解锁二人之力，第3局三世界并行且三人之力可供合法战斗选择。
3. 三世界同一天都有普通行动，每世界只有一份主要行动收益，三个独立随机流互不串扰。
4. 两个来源同一天向第三世界广播，各自有独立memoryId，接收者得到两份合法XP，不循环广播。
5. 来源世界在日终前saved/failed，不再进行普通记忆广播，但可留下合法回响。
6. 三人之力承载兽潮Lv3/P100/R14、兽王Lv5、两提供者Lv2+且未闭关、AP2/魂3：战斗+2合法，魂剩1。
7. 同样场景魂2：主动扣2后将归零，因此拒绝，不扣费。
8. 目标实际Lv2但临时+2可达到Boss要求：仍因基础资格Lv3而拒绝，AP/魂/R均不扣。
9. 一个提供者正在闭关、另一个已saved：三人之力拒绝，不强制出关。
10. 三人之力成功后来源下一3个全局日XP/R可缩放收益下降，实际Lv不降；不回溯当日行动。
11. 三人之力第t日使用，t+1至t+20均禁止二/三人再次使用，t+21可用。
12. 已有全球二人之力冷却，不能转而使用三人之力绕过。
13. 三世界损失一个世界后只能二人之力，失去两个后不能融合，但幸存世界仍可普通通关。
14. 同一目标刚被灵灾援助P，切换为兽潮援助D仍不能绕开按目标冷却。
15. saved的灵灾不能成为普通援助来源，但它的一次性回响可以给仍running的尸潮。
16. 灵灾回响与尸潮回响给同一running兽潮目标，符合各自一次性条件，不能重复消费。
17. 回响使用时目标已failed或已saved：拒绝并保留/明确处理不可用状态，不额外恢复世界。
18. 某世界失败灵魂-2并在同日达到全局0：其余仍运行世界按统一规则结束，不能在归零以后发起援助。
19. 三人融合战斗事件读档重新点击：事件已处理，不能再获得第二次奖励或创建第二枚回响。
20. 关闭战潮实验时全部融合规则与结果仍有唯一合法结算。
21. 开启战潮实验时一个三波精英事件只允许发生一次三人融合，不可每波融合一次。
22. 三世界都不发生融合、都没遇到稀有机缘：仍有独立、非随机的常规拯救路线，可能成功或因时间压力失败。
23. 全部世界saved/failed，局外碎片只结算一次；未使用的世界回响不会转成额外碎片。
24. 1×/4×、暂停、刷新、恢复存档后，冷却、事件、战潮构筑试验标记和世界状态不偏移。
