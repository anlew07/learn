# 双世界联动内容包 01 · 灵灾 × 尸潮

**版本 0.1 · 2026-11-12 · 设计稿，尚未编写游戏代码、未跑数值测试**

> 将两个独立世界的模拟结果通过同一灵魂连接；不修改五类自主行为和每日一项主要行动的原则。

## 1. 设计目标与适用范围

- 第一局已有**灵灾 + 尸潮同时运行**；被动记忆与主动资源援助可以出现。
- **第二局解锁二人之力**，让玩家在重大事件或母巢守卫终战中主动借用另一世界的力量。
- 世界在玩家不操作的情况下仍可各自完成主线或崩溃；借力与援助必须是加速或救急，不是获胜必需条件。
- 只在 SoulLinkSystem 中处理跨世界影响；世界包只能提交标准“重大经历候选 / 援助目标 / 可融合战斗”数据，不能直接操作对方世界字段。
- 不引入真实物品跨位面兑换商店、复杂灵魂技能树、双方同时参加同一个长期回合战斗等新玩法。

**正式的关联内容：**

| 内容 ID | 作用 | 发生方式 |
| --- | --- | --- |
| soul.memory.major_growth | 重大成长记忆 | 被动、日终广播 |
| soul.aid.progress | 提升目标世界拯救准备 P | 玩家即时操作 |
| soul.aid.stabilize | 降低目标世界毁灭 D | 玩家即时操作 |
| soul.fusion.two | 在一个已指定的重大/终局战斗中借力 | 第二局起，主动 |
| soul.echo.lingzai | 灵灾成功后的一次性回响 | 拯救成功时生成 |
| soul.echo.zombie | 尸潮成功后的一次性回响 | 拯救成功时生成 |

灵魂能力的 ID 不按具体人物和世界硬编码；相关事件通过通用接口声明能否使用。

## 2. 被动记忆共享：重大经历产生跨世界成长

### 2.1 可分享的经历

| 来源 | 具体触发 | 是否候选 |
| --- | --- | --- |
| 灵灾突破 | 首次达到筑基或金丹 | 是 |
| 灵灾精英 | 首次击败裂脉狼王 | 是 |
| 尸潮突破 | 首次达到猎杀者、清剿者 | 是 |
| 尸潮精英 | 首次击败停车场暴走体 | 是 |
| 每日修炼/训练/搜刮 | 普通单日行为 | 否 |
| 接受共享经验后升级 | 仅因共享经验触发的晋级 | **不允许再次广播** |

事件引擎可以另外标记某次特殊经历允许分享，但必须采用稳定的 sourceEventId 和 memoryKey；同一事件实例最多产生一次候选。

### 2.2 暂定规则

- 每来源世界**最多成功广播 3 次**，相邻广播之间至少经过 **5 个完整游戏日**。
- 一次成功广播对当前仍在运行的其他世界**各 XP+5**（暂定）；不会复制境界、母巢资料或灵石。
- 如果来源或目标在广播提交时已经 saved/failed，则不向这个对象正常广播。已拯救世界只能使用其一次性世界回响。
- 同一来源在同一天产生多个候选时，按**突破 > 首次精英战胜利 > 特殊探索**，再按稳定事件 ID 排序；只尝试最高优先级一个。已分享过的候选、因冷却或缺少可接收目标而不合格的候选**直接丢弃，不无限挂起**；不计入成功广播次数。
- 广播统一在“**两个世界日常结算、终局及世界状态检查之后**”执行。由此获得的升级可以在当日日志显示，但不得回溯改变本日已发生的战斗，也不再触发新的广播。
- 发奖与成功广播记录原子提交。再次读档不补发 XP，也不会因“共享升级”制造循环。

**具体示例：** 第 18 天灵灾达到筑基，如果两个世界都仍运行、该来源没有共享冷却，就在日终向尸潮发 XP+5。尸潮在第 18 天已经完成的清剿结果不变；第 19 天按新经验/等级进行行动决策。

## 3. 跨世界资源援助

物品无法物理跨世界直接通用：灵石不是废土零件。**援助将来源世界的4个专属资源转化为灵魂共鸣，作用到目标的 P 或 D；不直接增加目标的零件/灵石。** 这是游戏规则的统一转换，不是添加一种可屯积的第三资源。

| 援助 ID | 来源支付（暂定） | 目标收益（暂定） |
| --- | --- | --- |
| soul.aid.progress | R-4、AP-1、灵魂-1 | P+12（限制在100） |
| soul.aid.stabilize | R-4、AP-1、灵魂-1 | D-12（限制在0） |

### 3.1 双方与行动限制

- 来源、目标**必须是两个不同且处于 running 的世界**；来源 R≥4，未欠费；可用 AP≥1；主动消费灵魂后必须剩余≥1。
- 资源援助是一条**即时灵魂指令，不是来源分身的每日主要行动**：灵灾闭关时仍可作为援助来源（扣实际灵石），但不能参加战斗借力；两个操作不能混为一谈。
- 目标在获得 P 后若跨越 30/65/100 的主线阈值，按顺序**即时写入已有的非随机里程碑**，不重复发放 P。P100 仍不代表胜利；最终行动只能由玩家另外明确触发，或在本日正常终局检查时自动完成。援助本身不额外送一次“调查/封印”主要行动。
- 目标 D 只减至0，不向来源增加毁灭，也不改变目标已经清除的威胁状态；仍可能在本日环境阶段被自然恶化或活跃灾源重新增加 D。
- 来源资源 R 是**当前真实资源**，不是“已预留用于最终任务”的可消费副本。UI 若会打破最终材料储备，必须显示警告和新的缺口；玩家可主动确认使用。
- 援助冷却**统一按目标世界计算**：对同一个目标无论选择提升 P 或降低 D，需间隔 8 个完整游戏日；避免交替使用两种效果绕过冷却。以第20天成功援助为例，第21–28天均处于冷却，第29天起允许再次援助。此处明确替代早期“同目标同类型分别冷却”草案。
- 如未来扩展三世界：来源可不同，但**目标冷却仍共享**，不能换来源世界连续灌注同一个目标。

### 3.2 援助失败/重复指令

任何操作按“锁定来源/目标/能力/operationId → 检查状态与费用及冷却 → 预览 → 一次性提交双世界变化、AP/魂与目标冷却 → 检查结局、存档”处理。

操作不合法时**任何一侧都不改变**。操作已提交但客户端重复发送相同 operationId 时直接返回原结果；不可重复扣源世界资源、AP、魂力，也不可重复 +12 P/-12 D。

## 4. 二人之力：一次性战斗判定

**解锁：第二局。** 本包只做双世界。未来三人之力属于独立内容包，继续使用同一接口和全局冷却记录。

### 4.1 适用范围

- 灵灾“裂脉狼王”重大事件：战斗条件明确时可借尸潮力量。
- 尸潮“停车场暴走体”重大事件：战斗条件明确时可借灵灾力量。
- 尸潮“母巢守卫”终局战：目标实际 Lv≥3、P100、主线与 R≥12 等条件齐全但有效战力不足时可借力。
- 灵灾的**普通/古阵封印是条件型非战斗终局，不能使用二人之力替代境界或灵石**。

### 4.2 通用约束与费用（暂定）

| 项 | 二人之力 |
| --- | --- |
| 承载者 | 这一次指定战斗的目标分身，必须 running |
| 提供者 | 另一个世界 running、实际 Lv≥2、未闭关、可借出力量 |
| 效果 | **仅当前一次战斗**有效等级 +1 |
| 消耗 | AP1、灵魂强度1，主动消耗后魂力须剩余≥1 |
| 冷却 | 全局借力共用12个完整游戏日；第 t 天发动，第 t+13 天才可再次借力 |
| 后续代价 | 提供者在**之后3个游戏日的自动发展收益 -30%** |
| 与事件费用 | 本次融合 AP 替代普通“重大事件人工干预” AP，不重复收取 |
| 与当地强化选项 | 灵石强化/尸潮改装/二人之力**互斥**，不能串联叠加 |

有效战斗等级 = 目标实际等级 + 该次借力加成 - 目标状态惩罚；与敌人要求等级比较。**不能绕过实际等级、调查/主线标记、材料等非战斗前置条件。**

若目标已足以独立自动获胜，玩家原则上没有必要额外花 AP 借力。UI 仍应说明真实收益为0时不提供借力选项。

### 4.3 一次完整战斗事务

1. 用户打开**具体事件实例**或**当前终局挑战目标**，选择“二人之力”；不可对没有战斗对象的世界直接开 Buff。
2. 检查目标和来源存活、是否闭关、提供者实际等级、目标非战斗资格、活动事件/终局状态、共享冷却、目标受伤惩罚、可用 AP 和灵魂。
3. 计算目标当前有效战力及 +1 后结果。如果仍达不到战斗要求，显示“不足以获胜”，**拒绝而不扣费**。
4. 用户确认后**一次性提交**：扣 AP 和魂，结算这一个事件/终战，发放本次唯一奖励，写入提供者的三日虚弱状态、记录共享冷却。
5. 如世界因战斗获得 saved，创建对应**一次性回响**；若相关事件已处理或世界已结束，拒绝再次发起。
6. 整个流程立即保存。重复操作相同 operationId 只读取原结算结果。

这套处理只针对当前简化等级战斗。未来若加入有概率的非确定性战斗，必须在确定胜率提示、结果随机流和损失规则后单独调整，本包暂不启用“已知战力不足但强制花费魂力赌运气”。

### 4.4 提供者虚弱的精确定义

“发展收益-30%”只作用在提供者之后三次**有自动主要行动结算的游戏日**中产生的正向可缩放 XP 和资源收益；不降低战斗等级，不减少已获得的材料，不减少自然灾害与灾源压力，不缩减主线里程碑等离散奖励，也不削弱跨世界记忆的独立 XP。

为避免闭关/不行动无限延长虚弱，期限以**接下来3个实际推进的全局游戏日**计时，而不是以累计完成的普通行动次数计时；提供者若其间遇到受限制状态也不会冻结计时。整数资源缩放的舍入规则待数值层统一（不允许每次自行四舍五入产生漂移）。

**顺序：** 发动当天如来源当日的普通行动尚未结算，则仍从次一游戏日起开始扣减，不回溯影响当日已结算或即将结算的行为；在第 t+1、t+2、t+3 日结算后消失。此处取代旧文字中“未来3次日终发展结算”的可能歧义。

## 5. 闭关、世界结束与灵魂归零的边界

| 边界 | 灵魂援助 | 二人之力 |
| --- | --- | --- |
| 灵灾分身闭关中 | 允许灵灾作资源来源，实际扣灵石 | **禁止**灵灾作力量提供者 |
| 尸潮分身受伤 | 可正常接收 P/D 效果 | 有效战力会减去伤势惩罚 |
| 来源资源刚好4 | 若其他条件合法可以援助，R变0 | 二人之力不直接消耗来源世界 R |
| 目标已经 saved/failed | 不允许 | 不允许 |
| 来源刚完成拯救 | 不允许普通援助 | 不允许参加二人之力；仅保留回响 |
| 灵魂强度1 | 主动-1会归零，**禁止** | 主动-1会归零，**禁止** |
| 目标 D达到100 | 已崩溃不能“复活” | 已崩溃不能“复活” |
| 玩家强行出关 | 先独立支付强行出关惩罚并检查世界是否仍活跃 | 成功出关后重新校验才能借力 |

**世界回响：** 灵灾拯救成功生成一次 soul.echo.lingzai（暂定目标 D-10），尸潮拯救成功生成一次 soul.echo.zombie（暂定目标资源+6）。回响为免费、一次性、来源世界已结束仍可使用的特殊动作，目标必须还在 running；**它不能让已拯救分身继续参加二人之力**。当局没有其他运行世界时，回响自然无法使用，不产生额外奖励。

## 6. 玩家界面：清楚告诉玩家交换了什么

### 跨世界援助

在“灵魂”页：选择来源 → 选择目标 → 选择“推进拯救”或“压制毁灭” → 确认。预览必须同时展示来源 R、可用 AP、魂强度和目标 P/D 的**前后值**，还要显示是否打破来源的终局资源储备。

战报：

> 【万我同源】灵灾分身消耗4枚灵石与1点灵魂强度，将感悟投射至尸潮。尸潮拯救准备从78%升至90%。

### 二人之力

在已待处理的战斗事件/母巢终局页：“独自处理 / 当地强化 / 二人之力”互斥显示，附一份预览：

- 尸潮分身 Lv3 → 本次有效 Lv4（对手 Lv4）。
- 来源灵灾分身 Lv2，未闭关，可提供力量。
- 当前可用 AP 1，使用后 0；魂强度 5→4。
- 来源灵灾之后3个游戏日的成长和可缩放资源收益 -30%。
- 最早下一次可借力日（以当前 day 和冷却确定）。

若提供者正在闭关，按钮禁用并显示“灵灾闭关中，不能借出战斗力量”，而不是点了以后才隐藏扣费失败。

## 7. 存档最小合同

建议全局 SoulLinkState 仅保存：

- `memoryBySource`：每个来源广播次数、上次成功广播 day、已广播 memoryKey 集合。
- `memoryDeliveryLog`：不可递归的已结算发放记录（只需短期或操作去重所需的摘要）。
- `aidCooldownByTarget`：目标 worldId → nextEligibleDay；用于两种援助效果共用冷却。
- `fusionNextEligibleDay`：二人/三人之力共用全局下一可用游戏日。
- `operationResults`：operationId → 提交结果或最近操作签名；保证重复请求幂等。
- `echoes`：每个已拯救世界最多一个回响、目标约束、是否已使用。
- 各个来源 WorldState 的 `statusEffects` 保存独立魂力虚弱（开始日、结束日、效果），不由全局主动修改世界特殊数据。

本局游戏日与每个世界随机流均保存；内置事件的 instanceId、finaleResolutionId 要与 operationId 一并用于防重。当前仍在设计阶段，可后续调整 schema；首版正式公开之前不需要为了旧测试存档做迁移。

## 8. 因果演示：同样世界，不同选择

以下是**示意的可能经历，不是硬编码日程**。

- **第18日** 灵灾突破筑基，日终合法广播记忆；尸潮获得 XP+5。双方其它内容与末日时间照常推进。
- **第26日** 尸潮安全区 D=86、缺少时间清巢。玩家用灵灾4枚灵石、1 AP、1灵魂选择压制毁灭，尸潮 D=74；灵灾因此可能暂时缺少最终封印材料。
- **第45日** 尸潮实际 Lv3、P100、零件12，母巢守卫 Lv4。灵灾 Lv2、未闭关，二人之力合法 → 尸潮战力 +1，直接净化；灵灾随后3日成长收益下降。
- **另一条可能路线：** 灵灾正在闭关，不能借力；玩家可以用灵魂援助降低尸潮 D 等它独自升级 Lv4，或者强行出关并承担另外的灵魂与毁灭惩罚。**并非必须强行出关**。
- **如果灵灾先成功封印**，它立即停止普通行动，只留下可使用一次的灵灾回响，尸潮继续推进直到自己的结局。

## 9. 验收用例（设计测试，尚未执行程序）

1. 灵灾第一次突破筑基：尸潮仍 running → 日终 XP+5，仅一次。
2. 共享经验让尸潮升级：不再回传突破记忆，且第18日已结算战斗不变。
3. 来源当天突破和精英首杀：只按稳定优先级选一个记忆候选；其它候选不排无限队。
4. 没有 running 接收者或来源已结束：不发共享奖励，不占用广播次数。
5. 同来源连续几日重大经历：5完整日冷却正常生效；成功广播总数最多3。
6. 灵灾 R=4、可用 AP1、魂2、尸潮 P88：援助后灵灾R0/AP0/魂1、尸潮P100，里程碑仅一次，**仍需满足终局资格**。
7. 灵灾R3：援助失败，所有资源、AP、魂和目标 P/D 均不变。
8. 尸潮 D=6：D-12 的援助被限制到0，不会变负。
9. 第20日援助尸潮：第21–28日不能通过改用 P 型援助、换来源再次援助；第29日恢复。
10. 灵灾闭关并有足够 R/AP/魂：资源援助允许；二人之力禁用。
11. AP持有3、预留1：可用AP只有2，不能把预留点当作可直接消费点。
12. 尸潮 Lv3、R12、P100、目标守卫 Lv4，灵灾Lv2未闭关：二人之力+1，完成终局，成本只扣一次。
13. 灵灾正在闭关：禁止参与融合；强行出关须先承担独立成本，并重新校验世界状态和魂力。
14. 尸潮带轻伤(-1)导致 Lv3+1-1=3仍不能打 Lv4：拒绝借力，费用不扣。
15. 尸潮实际 Lv2，借力+1仍不满足终局 Lv3 基础资格：不能挑战，无任何费用。
16. 有效等级足够时原本能免费独立获胜：不提供没有收益的借力入口。
17. 灵灾狼王仅Lv2借力可胜后：精英奖励、清除狼巢、捐赠者虚弱和融合冷却原子提交；旧事件不重复发奖。
18. 二人之力本局第45日成功：第46–48日来源可缩放 XP/R 收益-30%，第49日起正常，不扣战斗等级；不可刷新提前结束。
