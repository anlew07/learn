# 尸潮内容包 01 · 废土生存、持续尸潮与母巢净化

**版本：0.1 · 2026-11-12 · 可评审的内容设计稿（尚无游戏代码，数值未测试）**

## 0. 本包目标与边界

构成完整的自动模拟闭环：

**训练/搜刮 → 清理感染体 → 发现停车场尸群 → 多日清剿或修补防线 → 调查感染根源 → 定位母巢 → 积累材料与实力 → 击败守卫、净化母巢。**

与灵灾一样每天只能执行**一个主要行动**。绝不再叠加旧版“策略每天固定给 XP、资源、P、D 收益”的实验模型。自然恶化和活跃尸群的持续压力在统一环境阶段独立结算。

特色是**材料储备与临时防御的两难**，不做居民数量、弹药、食物、感染率、防线耐久等额外常驻数值。尸潮没有闭关，灵灾可以闭关；不同世界仅共享统一接口而不互换专属规则。

## 1. 成长与资源

| 实际等级 | 称号 | 本世界可做的事 |
| ---: | --- | --- |
| 1 | 幸存者 | 训练、搜刮、处理落单感染体、基础调查 |
| 2 | 猎杀者 | 进入较危险街区，清理尸群外围、调查通讯站 |
| 3 | 清剿者 | 完成常规母巢净化的基础等级资格、挑战精英 |
| 4 | 末日猎手 | 能独力通过标准母巢守卫 Lv4 的战斗要求 |

**普通成长阶段按统一经验规则自动突破**。本包没有额外职业树；“战斗老手”“研究站资料”等是本局经历标记，不是新的永恒职业。

主要资源：**废土零件 R**，获得主要靠搜刮；可用于防线大修和最终净化。分身必须认识目标资源储备，不得无故把净化材料全花在普通维修上。

经验、掉落和零件门槛皆为**可替换的测试候选值**，不表示已经得到满意胜率。

## 2. 地点与自主行动

地点不是真实坐标地图，仅作为行动/事件条件；世界等级不足时不能因地点开放而强制挑战必败感染体。

| --- | --- | --- |
| site.zombie.shelter | 安全区外围 | 开局 |
| site.zombie.ruined_streets | 废弃街区 | 开局；高危敌人仍需 Lv2 |
| site.zombie.signal_station | 失联通讯站 | Lv2 或 P≥30；重大广播另有抽取条件 |
| site.zombie.research_complex | 地下研究设施 | P≥65 且已定位母巢线索 |
| site.zombie.mothernest | 母巢入口 | 已定位母巢、满足终局准备阶段 |

| 行为 ID | 主要行动 | 合法条件 | 一次结果（暂定） |
| --- | --- | --- | --- |
| action.zombie.train | 成长：训练与整备 | 世界运行中 | XP+2 |
| action.zombie.scavenge | 采集：搜刮零件 | 世界运行中 | R+2、XP+0.2 |
| action.zombie.patrol | 战斗：清理游荡感染体 | 未受阻、存在可胜的普通目标 | 采用选中敌人的战利品，不额外发“巡逻固定收益” |
| action.zombie.investigate | 探索：调查感染源 | P<65，世界运行中 | P+2.5、XP+0.4 |
| action.zombie.prepare_purification | 拯救：净化准备 | P≥65，已定位母巢，P<100 | P+3、XP+0.2 |
| action.zombie.clear_parking | 战斗：停车场外围清剿 | 尸群活跃、实际 Lv≥2，清剿进展<2 | 进展+1、XP+2、R+1、D-0.40 |
| action.zombie.repair_shelter | 专属：安全区大修 | 尚未大修、R≥6，达到下文安全阈值 | R-6、D-12；占用**当天一个主要行动** |
| action.zombie.trace_signal | 可选探索：追查广播坐标 | 有广播线索、P<65、未追踪过 | P+5、XP+0.2，标记一次性完成 |

**目标选择规则：** 若 P<65，拯救优先会倾向调查；若 P≥65 则倾向准备；若 P=100 但没有 Lv3、零件或最终战力，自动转向训练/搜刮/战斗，不反复加 P 或白白失败。成长策略提高训练偏好；清剿策略提高可胜感染体/停车场行动偏好。资源不足会抬高搜刮评分，当前重要目标的资源需求形成保留阈值。

## 3. 首批敌人及战斗合同

| 敌人 ID | 名称 | 类型 | 战斗要求 | 出现条件 | 胜利收益（暂定） |
| --- | --- | --- | ---: | --- | --- |
| enemy.zombie.wanderer | 游荡感染者 | 普通 | Lv1 | 安全区外围 | XP+2、R+1、D-0.20 |
| enemy.zombie.armored | 装甲感染者 | 普通 | Lv2 | 废弃街区 | XP+3、R+1、D-0.40 |
| enemy.zombie.parking_stalker | 停车场暴走体 | 精英 | Lv3 | 停车场清剿进展达 2/2 | XP+8、R+3、P+3、D-5 |
| enemy.zombie.mother_guard | 母巢守卫 | **最终首领** | Lv4（可因专属研究路线暂定降至3） | 终局资格满足 | 通过后净化母巢；不做可反复刷的战利品 |

**战斗判定遵循通用规则：** 有效等级 = 实际等级 + 合法临时加成 − 状态惩罚；有效等级达到敌人要求则通过。普通自主巡猎过滤必败目标，不用隐藏概率突然暴毙。被迫交战导致失败时，候选结果为 D+3、轻伤3次日终行动结算；失败没有战利品。同种轻伤不无限叠加，按更长剩余期限更新。

与灵灾保持统一：相对普通目标高出2级以上时 XP 奖励减半向下取整，不复制其它世界的怪物公式。二人之力的+1仅对**指定的一次战斗**生效；不会永久增加等级。普通尸群战斗不是单独一套战棋小游戏。

## 4. 持续威胁：地下停车场尸群

**模板 ID：threat.zombie.parking_horde**。每次创建独立威胁实例，并保存关联事件。

| 字段 | 规则候选 |
| --- | --- |
| 出现条件 | 第12天起、D≥20、世界运行中、该类型本局未生成 |
| 判定频率 | 每游戏日环境阶段检查一次，固定种子下暂定10% |
| 活跃限制 | 此类型每局一个实例；一个世界最多同时2处普通活跃威胁 |
| 状态 | active → awaiting_elite → cleared |
| 每日额外压力 | 活跃或等待精英时，每日环境阶段 D+0.30 |
| 外围清剿 | Lv2+，每个主要行动推进 1/2，不额外叠加普通巡猎掉落 |
| 精英事件排队 | 进展2/2后写唯一队列；最早下一游戏日激活 |
| 成功清除 | 解决关联精英事件后标记 cleared，停止该威胁之后的每日压力 |
| 再次出现 | 本局同一类型不再产生第二处停车场尸群 |

巢群出现即记录明确预警：“地下停车场正在聚集感染体，安全区压力持续升高。” 若已经有待处理重大事件，则只保留唯一排队记录，等待事件槽位空闲，不覆盖事件，也不能创建多个精英实例。

**结算时点：** 本日清剿或精英战先执行、环境后结算。如果本日 cleared，则当天**不再**对该尸群收 D+0.30；世界本来的自然恶化仍照常发生。以前造成的 D 不清零。

### 停车场暴走体重大事件

**ID：event.zombie.parking_stalker_raid**。清剿达2/2且槽位空闲后次日最早激活，处理窗暂定三个游戏日。

| 选项 | 条件 | 代价 | 结果 |
| --- | --- | --- | --- |
| 到期自动处理 | 实际战力足够 | 0 | 有效等级≥3则胜利，否则谨慎退避 |
| 玩家集中改装装备 | 实际 Lv≥2，强化后有效等级≥3 | AP1、R4 | 该战斗有效等级+1，胜利后清除尸群 |
| 二人/三人之力 | 符合共享冷却和提供者条件 | 各自全局费用 | 对该战斗临时 +1/+2，成功后来源虚弱 |
| 主动撤退 | 待处理 | 0 | 事件结束、尸群保留，暂定4个完整游戏日后允许重试 |

强化不能与二人/三人之力叠加成多个选项；它们是**互斥处理方式**。任何选项若算出来仍达不到战斗要求，应被拒绝，费用不得扣除。自动退避不按强制失败算伤害或额外扣资源。一个精英实例完成后永不重复发放奖励，新的尝试只允许新事件实例引用同一未清除的威胁。

清除后写入一次性标记：

- flag.zombie.parking_stalker_defeated：首次击败该暴走体。
- flag.zombie.infection_sample_found：获得一份**可选的**变异样本，用于未来研究分支。

没有击败精英或没有尸群生成，也必须能够通过普通调查找到母巢。

## 5. 尸潮专属：安全区防线大修

这是尸潮与灵灾闭关最不同的**资源取舍机制**。

- **使用条件**：当前世界运行中，尚未大修过，R≥6。
- **正常自主触发**：D≥55，且支付6个零件后**仍能保留至少12个净化预备零件**（即 R≥18）。
- **紧急自主触发**：D≥85 且 R≥6；允许打破预留规则，避免材料没用上就世界崩溃。
- **效果候选**：R-6、D-12。
- **次数限制**：每个世界每局最多一次；标记 flag.zombie.shelter_overhaul_used。
- **行动限制**：修复本身占当天唯一主要行动，不附带搜刮/训练/调查奖励。

该条件并不保证当日一定修复，而是使其成为高优先级合法行动。主线净化材料需求12也只是测试基准；如果未来正式调整材料费用，这个保留条件应读取 Finale 规则配置，不能硬编码成18。

**玩家干预：** 可以通过通用重大事件处理或跨世界资源援助来帮助防线；不另外增加一个可无限按的“修复按钮”。如果安全区已经自动大修过，后续靠清剿、援助和终局解决压力，而不是无限维修把 D 永久维持在低值。

战报示例：“分身动用了原本准备用于母巢净化的零件，完成安全区紧急修复；目前需重新积累净化材料。”

## 6. 非随机母巢主线：与灵灾相同的里程碑接口

**核心要求：** 没有抽中广播、没生成停车场尸群、没打赢精英时仍能通过常规行动完成调查。

| 里程碑 ID | 触发条件 | 一次性标记 | 内容变化 |
| --- | --- | --- | --- |
| milestone.zombie.infection_pattern | P首次≥30 | flag.zombie.infection_pattern | 确认感染体存在异常集结规律 |
| milestone.zombie.mothernest_located | P首次≥65 且前一标记存在 | flag.zombie.mothernest_located | 通过普通调查定位母巢与研究设施 |
| milestone.zombie.purification_prepared | P首次≥100 且母巢已定位 | flag.zombie.purification_prepared | 进入终局资格检查 |

里程碑只写标记、开放场所或战报，**不额外发一次 P**。若单次效果跨越多个阈值，按30→65→100依次补齐。此机制不占随机重大事件槽，也不消耗 AP。不能因为没有随机事件就永久停在 P65。

### 基础净化路线

需要同时满足：

1. world.status=running，D<100，未超过截止日。
2. P=100，已拥有 mothernest_located 和 purification_prepared。
3. 分身**实际 Lv≥3**，不能由魂力叠加绕过等级资格。
4. 废土零件 R≥12（候选值），且已经结束任何限制行动的特殊状态。
5. 当前母巢守卫战斗要求为 Lv4（可按研究线索降低）。
6. 一次合法的守卫胜利后，支付12零件，将世界标记 saved，并且只产生一次回响。

**自主终局**：若已满足所有资格且实际有效战力足够，日终在统一 FinaleSystem 中自动挑战并净化；不额外得到第二次主要行动奖励。若 Lv3 对 Lv4 不够，分身保持准备中，继续训练/搜刮，**不会自动每日送死**。玩家若有二人之力可主动按一次战斗 +1 补足；需要正常校验 AP、灵魂、提供者等级与状态、冷却。即使没有任何魂力联动，达到 Lv4 后也应能独自成功。

**主动失败处理**：当前第一包不启用“明知战力不足仍可强行挑战”的选项。所有尝试均在付款前校验，不让玩家无意义丢掉净化材料；将来若新增高风险挑战，必须独立写明失败成本和冷却规则。

### 可选研究捷径（不影响普通通关）

**flag.zombie.guard_weakness_identified**：通过可选广播/研究成功获得守卫弱点时，母巢守卫本次要求从 Lv4 调整到 Lv3；仍需要实际 Lv3、P100 与12零件。没有此经历可以通过实际 Lv4 或二人之力完成。该削弱不改变永久等级，也不改变其他首领。

## 7. 可选重大事件：失联广播

**ID：event.zombie.lost_signal**（沿用既有 ID）。

**触发候选**：Lv≥2、P≥30、已开放通讯站，分身执行探索时固定种子下暂定16%概率，本局最多一次；发现后通常次日激活。如当前已有重大事件，保留唯一候选并在槽位空闲后激活。

剧情：“通讯站接收到一段反复播放的求救广播。信号的发射位置竟与感染体异常集结的区域高度重合。”

| 处理方式 | AP | 结果候选 | 经历 |
| --- | ---: | --- | --- |
| 自动：记录并撤离 | 0 | P+2，保留信号坐标 | flag.zombie.signal_recorded |
| 玩家：深入追踪 | 1 | 70%成功：P+5并找到守卫弱点；30%失败：D+5、轻伤3日 | 成功写 guard_weakness_identified，失败写 signal_pursuit_failed |
| 玩家：放弃广播 | 0 | 不获得特殊收益，之后仍走普通主线 | flag.zombie.signal_declined |

有 signal_recorded 时，自动分身获得一次可选 action.zombie.trace_signal（P+5，写 signal_traced，P≥65后不再需要）；该行动占整天，不再叠加调查收益。没有广播或者主动失败都能走普通主线。

奖励和随机结果必须绑定单一事件实例。深入追踪需要玩家明确选择；默认自动选“记录并撤离”，避免不在线时因为剧情赌运气而被动损失。若选项不合法，先拒绝后不扣 AP。由于“记录并撤离”的 P+2 与一次性追查收益是两个不同时间的行为结果，它们可以分别获得，但不能在同一个日结算中再追加一份普通调查收益。

## 8. 成长、状态与跨世界联动

- 经验增加来自单一主要行动或合法的独立被动共享；不能同时得到旧版策略固定奖励。
- 轻伤是持续状态，默认降低一次战斗有效等级1；按剩余天数更新，不无限叠层。
- 灵魂分流的未来3日发展收益 -30%**不直接降低战斗等级**，维持通用规则。
- 重大首次成长与首次击败暴走体可成为记忆候选；记忆广播受每来源3次、间隔5日和不可递归规则。
- 二人/三人之力的战斗加成不永久修改实际 Lv；已结束世界不能借力。终局战不存在额外重复“普通重大事件 AP 费用”。
- 尸潮世界拯救成功后只创建一次世界回响，候选为其他运行世界资源+6；当前世界不再普通挂机。

## 9. 保存字段与日志

WorldState 保存：已开放地点、P/D、等级经验 R、策略/行动目标、三个主线标记、shelterOverhaulUsed、活跃 threatInstanceId、停车场 progress/status/eliteQueued/nextEligibleDay、广播 eventInstanceId/结果/候选排队、flag.zombie.guard_weakness_identified、最终守卫状态与最终操作唯一 ID、世界随机流状态。已处理事件实例保存 resolution 与 rewardGranted，世界 saved/failed 后不再产生普通活动。

主界面显示“尸潮压力、活跃集结点数量、当前行动、母巢准备缺口”；不显示额外的感染人口/食物/弹药进度条。普通感染体日志合并；发现广播、成功清巢、紧急修复和最终净化独立突出。

## 10. 设计验收用例（尚未执行程序测试）

1. **完全不抽广播且不生停车场尸群**：普通 investigate → P30/65 → prepare → P100；Lv4、R12可自动净化。
2. P从28一次跳到70：按顺序写 infection_pattern 和 mothernest_located，不追加额外 P。
3. P100但 Lv2 / R不足：不得触发母巢战、不得扣零件；选择训练或搜刮。
4. P100、Lv3、R12、无研究弱点：不会盲目挑战 Lv4；二人之力合法时可一次性补足。
5. P100、Lv4、R12：无需玩家操作可独立完成最终净化。
6. 有弱点标记、Lv3、R12：只在母巢守卫战降低对手要求，仍需基础资格。
7. 普通 Lv1 自动巡逻不主动选 Lv2 装甲感染者。
8. Lv2 连续两次清剿停车场：进展0→1→2，不能额外领取普通巡逻奖励。
9. 2/2有其他重大事件：暴走体排队不覆盖；次日最早激活且只创建一个实例。
10. 清除停车场当日：不再算该节点 D+0.30，自然恶化仍发生。
11. Lv2且带轻伤，装备强化后战力仍不足：拒绝强化，AP/R不扣。
12. 独立事件实例重试：新实例引用同一停车场，但已发的首次奖励不能重领。
13. D≥55且R18、未大修：可执行大修，R12、D-12，且不额外搜刮。
14. D≥55且R10、未到紧急阈值：保留最终资源，不自动大修。
15. D≥85且R6：允许紧急大修，即使之后缺净化材料；必须重新搜刮。
16. 大修已使用：再次满足阈值也不能再次领取 R-6/D-12。
