# UI 视觉方向 · 2026-11 独立实验分支

> 目标：保留已验证的自动模拟 / 战潮 / 存档行为，只提升首页第一印象、世界辨识和战斗反馈层次。此文件属于视觉实现文档，不改玩法基线。

## 强制风格基线（高于下方早期实验描述）

> 本节是当前生效的最终美术约束。旧实验中的渐变、柔光、模糊、玻璃质感等描述如与本节冲突，一律以本节为准；不代表旧 CSS 已自动完成整改。

- **统一 2D Pixel Art：** 主界面、世界场景、角色、敌人、技能、按钮、边框、面板和装饰全部使用一致的像素 RPG / 像素生存游戏语言，不允许按页面或素材混搭画风。
- **统一网格与轮廓：** 采用整数像素网格、清晰硬边轮廓、明确剪影；SVG 使用 `crispEdges`，放大使用最近邻像素化。避免半像素定位、柔化边缘和抗锯齿造成的糊边。
- **有限色板：** 共享基础色板与三世界强调色，控制单素材颜色数量；面板、按钮、场景、角色和图标的明暗/描边规则一致。
- **禁止冲突风格：** 不使用写实插画、摄影质感、3D、玻璃拟态、磨砂模糊、霓虹渐变科技风。主视觉以平涂色块、硬边描线、阶梯边框和硬边像素阴影为主；不以渐变、模糊滤镜、柔光或玻璃高光营造科技感。
- **文字保持可读：** 中文正文无需像素字体；系统字体优先，标题/短数字可选择像素字体，但不得牺牲正文辨识度。
- **手机竖屏优先：** 320–430 CSS px 下信息层级清晰、无横向溢出、重要触控目标至少 44px、底部安全区正确；动画与滤镜需考虑低端设备开销。
- **轻量且可替换：** 优先轻量 SVG、CSS 像素块和精灵图；素材独立管理，不引入大型框架/引擎/远端资源。

验收以整个游戏的一致性为准，不以“某一张图已经像素化”代替全局验收。当前旧版基础 CSS 仍存在部分渐变、圆角和模糊效果；这些属于待逐步清理的历史视觉债务，不视为符合新规范。

## 设计方向

**末日奇幻 / 战术情报板 / 三界异象。** 主界面继续使用深色、留白和高对比数据，但减少纯粹的表单感。主色为幽蓝底色；共享状态以青绿色强调；灵灾用翡翠青、尸潮用余烬橙、兽潮用暮紫。重要提示沿用告警黄和危险红，避免只靠颜色表达状态。

- 首页：中心灵魂传送门作为主视觉，保留原有启动、继续、重开、战潮开关和档案结构。
- 世界卡：使用三个轻量、可缩放的原创 SVG 作为卡片顶部氛围图；对文字采用遮罩和低不透明度，不抢占可读性。
- 战潮：加强**已结算**清剿数字、三波信息和回放舞台层次；绝不新增收益、随机逻辑、战斗按钮或存档字段。
- 导航与控件：提升选中状态、操作按钮、键盘聚焦和窄屏触控尺寸，保留 `data-action` 和 ARIA。

## 集成与维护

- 这一轮**不引入新框架、组件库、运行时状态或依赖**；复用已有 HTML 结构、CSS 和 Vite 资源管线。
- 未来页面改动优先修改 `src/style.css` 的结构样式；仅将视觉覆盖和艺术资源保留在 `src/art-direction.css`，逐步合并重复声明，避免长期堆积覆盖。
- 三个世界的状态标识文字、百分比、按钮禁用状态均由原引擎保留；插画只用伪元素呈现，绝不承载关键信息。
- `prefers-reduced-motion: reduce` 下关闭新增传送门呼吸动画；已有战斗回放使用原有的无障碍退化方案。
- 插画 SVG 不含动态脚本、外链和可执行内容。

## 像素风方向确定：Pixel Art v1（2026-11-13）

用户已确定以**轻量像素末日**代替原有的细节插画风。本次不是另建引擎或用位图批量贴图，而是把已存在的 10 张 SVG 全部重新制作成规则整数像素网格，另新增 1 张九式战技合并图集：

- 16×16：精英敌潮标识 + 九式战技的每格图标；
- 32×32：三世界分身小头像；
- 64×64：共享灵魂传送门；
- 128×72：三世界场景插画。
- 11 张 SVG 总大小 **13,857 字节（原始 UTF-8，未压缩）**；小于新增自动化约束的 17 KiB 上限。
- 图集映射：`basic, chain, pierce, fan, flurry, shockwave, storm, barrage, hunt`（见 [画廊](12-ui-art-gallery.md)）。
- 原有 `src/ui.js` 仍然只改动一行样式 import；像素图通过 `src/art-direction.css` 覆盖层引用。
- 缩放采用 `shape-rendering="crispEdges"` 和 `image-rendering: pixelated`，不把文字渲染成马赛克，也不牺牲信息可读性。
- 每张像素图只使用简单 `<path>` 和不超过 9 种颜色，没有新增插件、字体、图片服务器、Canvas 或建置脚本。
- 所有精英视觉与连锁/穿透/弹幕等战斗图标只反映现有引擎状态，绝不创造战斗结果。

保持 **Draft PR，未合并至主线**。在主线持续更新的阶段，不对其文件进行覆盖；合并前再与最新 `main` 对齐。
