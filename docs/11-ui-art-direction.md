# UI 视觉方向 · 2026-11 独立实验分支

> 目标：保留已验证的自动模拟 / 战潮 / 存档行为，只提升首页第一印象、世界辨识和战斗反馈层次。此文件属于视觉实现文档，不改玩法基线。

## 设计方向

**末日奇幻 / 战术情报板 / 三界异象。** 主界面继续使用深色、留白和高对比数据，但减少纯粹的表单感。主色为幽蓝底色；共享状态以青绿色强调；灵灾用翡翠青、尸潮用余烬橙、兽潮用暮紫。重要提示沿用告警黄和危险红，避免只靠颜色表达状态。

- 首页：中心灵魂传送门作为主视觉，保留原有启动、继续、重开、战潮开关和档案结构。
- 世界卡：使用三个轻量、可缩放的原创 SVG 作为卡片顶部氛围图；对文字采用遮罩和低不透明度，不抢占可读性。
- 战潮：加强**已结算**清剿数字、三波信息和回放舞台层次；绝不新增收益、随机逻辑、战斗按钮或存档字段。
- 导航与控件：提升选中状态、操作按钮、键盘聚焦和窄屏触控尺寸，保留 `data-action` 和 ARIA。

## 集成与维护

- 这一轮**不引入新框架、组件库、运行时状态或依赖**；复用已有 HTML 结构、CSS 和 Vite 资源管线。
- 未来页面改动优先修改 `src/style.css` 的结构样式；仅将视觉覆盖和艺术资源保留在 `src/art-direction.css`，逐步合并重复声明，避免长期堆积覆盖。
- 三个世界的状态标识文字、百分比、按钮禁用状态均由原引擎保留；插画只用伪元素呈现，绝不承载关键信息。
- `prefers-reduced-motion: reduce` 下关闭新增传送门呼吸动画；已有战斗回放使用原有的无障碍退化方案。
- 插画 SVG 不含动态脚本、外链和可执行内容。
