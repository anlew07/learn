# 02 · 每日运行、事件与结局

**约定：** “游戏日”是离散结算单位；现实秒数只决定何时推进。1× 暂定 20 秒/日；2× 10 秒/日；4× 5 秒/日。暂停与切后台不做离线补算。

## 全局游戏日

1. **日初**：到期行动点恢复、前日结束状态处理、激活预定重大事件和闭关安排。
2. **玩家操作窗口**：可即时变更策略、处理事件、援助与安排闭关。查看重大事件详情时临时冻结计时。
3. **到期事件**：处理到期且未回应的事件；同一实例只结算一次。
4. **世界自动行动**：对仍运行的世界用当日有效状态选一个主要行为；仅一个世界处于闭关则该世界执行闭关，不停止其他世界。
5. **环境与持续威胁**：自然恶化、活跃灾源、世界事件按独立来源结算，不重复计算。
6. **成长与主线**：突破、经历标记、内容解锁和终局资格；正常可完成的最终行动自动执行。
7. **结局**：拯救、毁灭 100、截止日和全局灵魂归零检查。
8. **被动共享**：当日重大经历产生的记忆汇总后广播，影响下一日，不反向重演本日战斗。
9. **完整快照保存**：保存后推进日序；不重复结算。

一次即时效果使毁灭达 100 时直接崩溃；未崩溃且最终行动成功时立即拯救。截止日日终仍未完成终局则崩溃。主动操作即时提交后也要立即检查结局。

## 重大事件

- 初始目标：重大事件约 9–14 日一次；首次约开局 6–9 日出现，**数值待测试**。
- 一世界最多一个尚未解决的重大事件；普通日志、自然灾害不受此限制。
- 发现的重大事件通常在下一游戏日进入可选窗口。
- 举例：第 21 日激活，则第 21、22、23 日可干预，第 23 日日终无人处理则自动决策。
- 事件有模板 ID 和本局实例 ID，必须保存实例与已确定的结果/随机状态。
- 自主处理与玩家处理互斥，不重复奖励；因世界结束而失效的未决事件标记“作废”。

## 战斗与持续威胁：统一结算约定

战斗是每日一个主要行动，不额外叠加旧版策略固定 XP/R/P/D 日收益。有效战斗等级 = 分身实际等级 + 合法临时战力修正 - 状态惩罚；达到对手等级才正常胜利。自主狩猎先过滤必败敌人，只有明确的被迫交战事件才结算失败伤势。所有费用与奖励整体检查后一次性提交。

持续威胁节点于日终环境阶段施加额外压力；**当天已清除的节点当天不再施压**，自然恶化仍照常发生。每世界最多两个普通活跃威胁。重要首领事件由清剿进展排队触发，最早次日出现；若待处理事件槽位已满，应保留一个唯一队列记录，不能覆盖或重复生成。详见 [灵灾内容包 02](../content/packages/lingzai/02-beasts.md)。

## 行动点与灵魂

| 项 | 基准（暂定平衡数值） |
| --- | --- |
| 初始行动点 | 2 |
| 上限 | 4 |
| 恢复 | 第 9、17、25 日等，每 8 日 +2 |
| 策略切换 | 1 AP |
| 重大事件干预 | 1 AP |
| 资源援助 | 1 AP +1 灵魂强度 + 来源资源 |
| 紧急救援 | 2 AP +2 灵魂强度 |
| 闭关 | **预留**1 AP，正常结束释放，非消耗 |
| 初始灵魂强度 | 8 |
| 世界崩溃 | -2 灵魂强度 |

持有 AP 减去预留 AP = 可用 AP；恢复最多使持有 AP 达 4，不能将预留 AP 当成消耗来钻上限。主动灵魂消耗需留至少 1 点；被动崩溃扣除可令强度归零，随后结束尚运行的世界。

## 闭关与持续状态

安排闭关在下一游戏日生效；闭关占用当日唯一主要行动；其他世界和灵灾环境继续。短/长闭关暂定 4/6 日；正常出关释放预留点。事故仅在完成时判断一次，强行出关的惩罚只执行一次。借力的虚弱从其后 **3 次日终发展结算**生效；暂停/加速不能改变持续天数。

## 终局：必须区分准备与真正拯救

拯救进度达到 100 表示主要调查和准备达成，**不是胜利**。还须基础等级、必要主线、资源与最终行动成功。最终行动有准备中、待战、冷却、已成功/已失败状态。条件不足时分身继续准备，不要自动每日送死；资源成功时按世界规则扣除；战斗失败只扣规定部分材料并进入冷却（具体待测试）。

最终挑战是主线目标而非随机重大事件；二人/三人之力可补战斗等级，不能跳过基础等级、主线和资源。无稀有机缘的基础路线必须存在。

## 非随机主线里程碑与灵灾条件型终局

主线里程碑不属于随机重大事件：达到配置进度阈值与前置条件后仅写一次标记，不占重大事件窗口、不额外加 P；同次效果跨多个阈值时应按顺序完成合法里程碑。

P100 只是准备完成，还需实际成长等级、主线标记与资源。不同世界可定义**条件型非战斗终局**或首领战终局：灵灾的标准封印与古阵封印都不强制首领战。闭关中的分身不能执行需亲自完成的封印。

灵灾条件全部满足后，日终自动封印一次，不添加第二份主要行动奖励；若玩家日初主动执行封印则即时结束该世界，不再执行本日行动。费用、saved 状态和回响只提交一次。P100 而缺实力或材料时保持准备中、继续修炼/采集，不扣材料、不自动失败。详见 [灵灾内容包03](../content/packages/lingzai/03-exploration-seal.md)。

## 世界冻结与结算

状态只有运行中/已拯救/已崩溃；结束后不再普通挂机或接受援助；拯救世界可能留下一个免费的世界回响。全世界结束或灵魂归零，本局结算一次；用 runId 防重复奖励。

**尚未验证的边界：** 行动点频率、长局耗时、闭关事故率、末日曲线和各世界胜率需自动模拟与试玩。

## 双世界联动的日结算与主动操作边界

双世界的记忆候选在每个世界当日普通行动和结局处理完成后统一评估，来源和接收者此时都应 running；广播XP不会重演已结算战斗，升级不能再触发新的记忆广播。

资源援助为玩家即时指令，先完整检查来源R、目标running、AP、魂与**按目标共用**的8个完整游戏日冷却，再一次性提交；P援助跨主线阈值时同步写里程碑，但不会自动额外执行一项主要行动或终局挑战。

二人/三人之力只面向指定重大/终局战斗；必须先通过非战斗资格与有效战力预检。成功后提供者从下一游戏日起连续3个全局游戏日得到可缩放自动XP/资源收益-30%的状态；闭关或世界结束不能提供战斗力量。具体样板详见[双世界联动内容包01](../content/packages/soul-link/01-dual-world.md)。
