## 结论与落地决定

**没有足够证据批准本轮任一数值候选。** 冷却缩至 2s 或 1s，或伤害由 1→2、目标数由 1→2，虽能提高雷击命中或少量击退，却没有建立稳定的资源收益优势；聚灵阵纹在余命上继续明显领先。**不修改 `src/config/sortie-data.js` 的 2G 参数：驭雷符 4 秒 / 1 目标 / 1 伤害，聚灵阵纹 25 秒充能。** 这不是“战技已经平衡”的结论。

本 PR 的实际增量是可复验的专属测试与本报告；没有修改敌人、拾取/掉落、剑台、正式存档、双世界结算或其他并行分支文件。

## 无剑台、绕场：核心对照

每格表示 **平均击退 / 平均余命 / 次场灵石**；n=40，全部 40/40 通关。

| 战技/候选 | D=0 | D=40 | D=75 |
|---|---|---|---|
| 聚灵阵纹 25s | 23.05 / 6.60 / 3.45 | 25.63 / 6.45 / 3.48 | 28.08 / 5.75 / 3.53 |
| 原雷：4s | 23.05 / 5.00 / 3.38 | 25.75 / 4.93 / 3.48 | 28.13 / 3.90 / 3.38 |
| 雷：2s | 23.18 / 4.90 / 3.35 | 26.13 / 4.90 / 3.35 | 28.43 / 3.90 / 3.30 |
| 雷：1s | 23.18 / 4.88 / 3.18 | 26.18 / 4.93 / 3.28 | 28.50 / 4.03 / 3.13 |
| 雷：2 伤害 | 23.05 / 5.00 / 3.38 | 25.78 / 4.90 / 3.48 | 28.13 / 3.95 / 3.38 |
| 雷：2 目标 | 23.05 / 5.00 / 3.38 | 25.75 / 4.90 / 3.43 | 28.15 / 3.93 / 3.38 |

- 冷却 1s 时，D=40 绕场雷击命中 **5.08→15.30**，击退却只 **25.75→26.18**；相对符文多击退 0.55、少余命 1.52、少次场灵石 0.20。D=75 相对原雷多击退 0.37，次场灵石反而 **3.38→3.13**。
- 冷却 2s 相比 1s，击退略低、但获得灵石较高；两者均未转化成资源优势。单次伤害 2 与双目标对最终结果影响更弱，不能据此承诺玩法改善。
- D=0/40/75 的**站桩雷均 0/40**；符文站桩为 **40/40、0/40、0/40**；两个战技的绕场/拾取均 **40/40**。没有出现新的、可判别的主动操作通关梯度。高危余命下降，说明受击梯度仍在。
- 主动拾取策略下各版本次场灵石基本都是上限 **5**；雷的更高命中无法兑现额外兑换。造剑台组同样没有发现可普遍兑现的雷专属灵石优势，且有 6 灵石建造成本。
- 第二场最终灵灾资源不只由雷击决定，还包含建设选择与跨世界每日结算；不能把单项资源差直接当作雷击的独立“掉落产出”。

## 原因与风险

当前每场敌人数受固定波次限制，D=0/40/75 的计划生成量分别为 24/27/30；基础灵刃已经能在移动策略下击退绝大多数敌人。雷的额外命中常替代灵刃本来就会完成的击退，并且可能改变掉落位置与拾取路线。因而**命中次数不等于新增击退，更不等于新增灵石**。当前测试不直接测量提前击退的时间分布，所以不能排除雷改善了短时间内的火力手感；但已有结果不足以作为平衡通过证据。
