# 灵灾出击 · 阶段 2A 战场落地记录

> 2026-11-17。开发基线：正式 main@b9d28f09。设计参照待合并 [PR #64](https://github.com/anlew07/learn/pull/64)；本 PR 不代表已经批准把主游戏改成实时战斗。

## 实际范围

- 正式首页提供“灵灾战斗试玩”入口；`?mode=sortie` 使用独立引导和战斗场景，不加载旧 UI 或正式存档服务。
- 320×448 Canvas 固定逻辑地图，项目内已有原创角色/妖兽 SVG；移动可用左摇杆、键盘 WASD/方向键。
- 基础灵刃自动寻找最近敌人，狼/妖影分波靠近；命中扣生命、接触掉血、短无敌、75秒胜负与结束成绩。
- 暂停、失焦、后台暂停；刷新从新战斗起点开始，正式世界日、灵石、永久成长均**不发生变化**。
- 纯战斗规则使用固定 60Hz tick 和独立 seed；Canvas 只能读取不变更战场状态；无大型新依赖。

## 与完整闭环的边界

目前**没有**战技二选一、拾取/灵石收益、营地建设、双世界日结算、存档、跨界援助。下一阶段先验证核心移动和命中好不好玩，再按照 [07 任务拆分](07-core-loop-delivery-plan.md)分 PR 加入经济/世界桥接。

## 质量门禁

本地或 CI 执行 lint、Vitest、build、Playwright；明确记录实际结果和未能验证的真机。检查正式游戏仍可开始、暂停、读取旧档。特别验证不同刷新率、重复种子、生命 0 和 75 秒成功；本阶段没有真实移动端设备验证或用户试玩，不要把脚本当作真人证据。

参考 MDN `requestAnimationFrame`、Pointer Events 与 Page Visibility API；代码不复制其他商业游戏资源。
