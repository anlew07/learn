# 2M｜文明演化图谱：真实结算驱动的目标地图

> 2026-11-19。基线为 2L A/B/C 已合入的 **2G 隔离出击分支**。本 PR 不接入正式 Run/Profile，不部署 main，不改变出击难度、灵石奖励、剑台成本、技能数值或存档结构。

## 本轮为什么这样做

借鉴《卡包英雄》技能树的「目标可见、完成任务推动下一阶段、节点开启期待」，**不照搬抽卡和庞大的永久加成**。当前实验版已有 75 秒真实出击、险地回收奖励、双世界结算、6 灵石永久剑台，但其动作前后缺少连续成长路线说明。若直接加一堆升级，会让已有的经济和风险难以验证。

第一轮因此只做**零资源新产出的可验证成长地图**，而非引入另一套影子升级币或假奖励。

## 节点合同

| 节点 | 前提 | 真实完成依据 | 说明 |
| --- | --- | --- | --- |
| 文明火种 | 创建营地 | 固有起点 | 玩家已能选择灵灾出击、废土日行动 |
| 雾谷生还 | 可立即尝试 | 出击权威账本存在 won 回执 | 奖励仍按原 3 石、经验和碎片结算 |
| 拾荒之路 | 可立即尝试 | 单场回执实际拾取 ≥3 片且换到 ≥1 灵石 | 不增加原有最多 2 石碎片兑换上限 |
| 险地回收 | 可立即尝试 | won + salvage + completed + 实际奖金 2 石 | 不能仅凭点击险地按钮或接触目标点亮 |
| 双界纪事 | 可立即尝试 | 权威回执使一天真实推进、灵灾和废土均有当日行 | 不虚构跨世界传送新资源 |
| 修复剑台 | 完成首场出击 | 原建造回执、forgeLevel=1 | 必须实际付 6 灵石，永久伤害 1→2 |
| 灵刃实战 | 剑台建成 | 建造后另一场 won 回执且 weaponDamage=2 | 不是点了建造就把战斗收益标已验证 |
| 文明初芽 | 回收 + 剑台实战 + 双界 | 同时完成前述条件且 ≥2 场赢 | 纯阶段里程碑，不发未验证额外收益 |

*「前提」仅决定目标的展示阶段；战场与建造的最终资格、付费和结算始终由原有权威接口决定。*
本阶段保留玩家自由选择是否先修剑台：任何节点都不强制绑定消费或赠送材料。

## 手机入口

营地现有交互顺序不变：出击、任务选择、资源预算、营地、剑台。图谱放在剑台下方，手机默认折叠，只显示达成进度和当前建议。打开可查看 8 个节点及每个真实条件；「查看任务／投资／出击」按钮只滚动到已有入口，不直接下单、不开始出击，避免 320px 屏误触。

采用原生 `details/summary`、DOM 文本节点、少量 CSS，不加视图库。节点与进度由独立纯函数 `previewCivilizationProgress` 统一生成，不向 IndexedDB 写入新字段；刷新和跨设备屏幕尺寸不会凭空增加进度。

## 门禁与下一步

- 单测验证：新档仅点亮起点；pending 不能点亮；真实 75 秒两场战斗与真付 6 石激活相应节点；未完成/失败/奖金 0 不点亮险地回收；预览不修改档。
- 三种竖屏尺寸通过真实手指滚动打开图谱和点击导航，导航后必须仍未购买或接取任务。
- 完整 CI：ESLint、Prettier、Vitest、Vite、既有固定种子与 Playwright；必须以最终 HEAD 成功为准。
- 尚需后续产品验证：玩家是否更容易找到下一步、是否理解两条成长路线；尤其剑台原有固定种子回本问题未解决。后续如验证真正的第二条经济选择，优先在独立小实验中研究 2 石战前准备的实战价值，而不是凭好看先变成正式节点。

**本 PR 不是正式游戏升级系统，也不是已批准的大型科技树；它是与现有战斗/营地同源的目标表达层。**
