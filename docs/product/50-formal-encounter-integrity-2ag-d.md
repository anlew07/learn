# 2AG-D · 正式遭遇事务与主线规则完整性

> 基线：PR #132 / ed4be99eea773c617128cf89f3a0940add0e5546。
> 本轮修复验收中发现的阻断项，不扩展第二世界，不改变战斗时长或新增运行时依赖。

## 修复

- pending encounter 存在时禁止公开 Engine.step、干预命令和直接干预接口改变正式世界；相同已处理操作的幂等回放仍然有效。预览只在克隆上运行。
- 正式遭遇结算从内部事务入口执行；独立试玩 API 不能通过请求标志冒充正式回执，两类回执不能跨接口重复提交。
- 正式 fight 消耗一次真实行动决策 RNG。胜利时推进已有外围威胁进度，达到两次排险后进入原首领待挑战状态。普通排险胜利沿用原危机减缓值；巢群排险沿用原 0.6 减缓值。撤离和失败不获得威胁进度或该减缓。
- 不额外支付原自动排险的资源和经验，不改变已存在的实时战斗奖励公式。该公式仍须经过正式经济对照实验，不能视为已平衡。
- 已购买集中火力但尚未消费的战斗，暂时走旧三波权威结算；等实时战斗有真正的战术支援效果后再迁移，不能无故扣掉已购买权益。
- 正式遭遇期间锁定无关导航和干预。战斗结果在 RunState 与 ProfileState 成功原子写入后才发布。失败保留终止轨迹，先重试保存再重试结算。提交期间的后台、pagehide 等普通保存不会排队覆盖新回执。
- 重新生成源码审查 CSV，移除上游临时的 CI 自动导出步骤，恢复直接验证已提交文案清单。

## 验证

新增引擎回归：冻结日历与干预、胜利推进威胁、撤离不推进、试玩接口隔离、集中火力消费与幂等。
新增浏览器故障注入：最终写入失败时不展示奖励、日期保持原值，重试保存及结算后只推进一天。
保留 2AG-C 三种视口、原有固定种子实验及全量 CI。
