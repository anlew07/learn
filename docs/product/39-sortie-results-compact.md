# 2U · 雾谷战后结算游戏化收口（2026-11-20）

## 问题与目标

2T 已把营地首屏收成战果、任务、剑台、出击，但战斗结束仍默认展示奖励公式和两世界长篇结算，遮蔽成就反馈与下一步。目标是让玩家一眼回答：赢了没有、拿到什么、世界发生什么、下一步去哪里。

## 本轮设计

- 胜败主标题加简短生存/击退统计，像游戏关卡结束界面。
- 真实权威回执的灵石、经验、救援准备、拾取碎片和任务奖金继续用四至五格数字展示。
- 以**来自已提交回执**的世界资源 delta 展示两条简短摘要，「双世界已推进第 N 日」，不新造效果或资源。
- 奖励公式、实际行动和完整双世界日变化保留原有 DOM 和回执文案，折叠在浏览器原生 `<details>/<summary>`，需要时真实触摸展开。方案符合主流浏览器支持的无依赖渐进披露模式。
- 结算明确区分「正在核对并保存」「✓ 战果已保存」「保存失败」。**只有保存成功才启用返回营地按钮**。出现验证/写入失败时保持原有重试保存通道，不允许未入档显示成成功。
- 底部回营按钮与滚动战报物理分离，小屏保持可触摸，不覆盖详情控件。
- 保留 `data-sortie-gains`、`data-sortie-reward-preview`、`data-sortie-world-report`、`data-sortie-growth-result`、`data-sortie-retry` 等已有 QA 合同与全部真实数值。

## 不涉及

不更改战斗、技能、奖励公式、险地任务奖金、IDB 存档版本、正式模拟器入口或双世界结算权威接口。

## 验收

三款手机（320×568、390×844、430×932）通过真实触控：撤离→权威结算→保存成功→奖励数字和双世界摘要→默认收起的完整记录→固定回营按钮→营地天数递增→刷新不重复结算、正式档不受影响。并执行 CI 现有全部战斗、经济、存档、文明图谱回归。TapTap 真机与新玩家无提示试玩仍需真实设备/用户补验。
