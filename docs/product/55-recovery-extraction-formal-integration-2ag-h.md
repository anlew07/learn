# 2AG-H：回收目标与主动撤离正式集成

## 产品结论

2AG-G 的 480 场精确固定种子配对实验确认：回收目标完成后主动撤离可兑现 +2 灵石，能形成低收益保底与高收益冒险之间的选择。正式接入范围仅限主游戏的正式世界遭遇，不改变独立试玩档的奖励规则。

## 玩家流程

1. 灵灾排险遭遇开始前，玩家选择「稳妥巡护」或「险地回收」。
2. 稳妥巡护保留原有战斗流程；险地回收需要本源意识接管移动，AI 开局不提供该任务。
3. 险地回收点在战斗中出现，HUD 显示倒计时、守卫状态与驻留进度。
4. 完成回收后，HUD 明确显示「撤离保留 +2 灵石」，撤离按钮同步显示可兑现奖励。
5. 玩家可以立即撤离锁定奖励，也可以继续战斗拾取碎片、争取胜利奖励。完成目标后交还 AI 不会丢失已完成目标。
6. 战斗结算说明目标是否完成、奖励是否兑现及原因。

## 权威结算规则

| 结局 | 回收目标 | 目标奖励 |
|---|---|---:|
| 胜利 | 已完成 | +2 灵石（原规则不变） |
| 主动撤离 | 已完成 | +2 灵石（新增） |
| 死亡 | 已完成 | 0 |
| 主动撤离 | 未完成 / 失效 | 0 |
| 任意结局 | 稳妥巡护 | 0 |

正式 Engine 在验证完整动作轨迹后才结算奖励；奖励只进入现有单日交易与回执，重复结算仍由 sortie ledger 幂等保护。前一日残留的任务选择自动回落为稳妥巡护，不能阻塞下一天。

为避免改变独立试玩档，只有正式遭遇调用奖励预览时才启用 `bankObjectiveOnRetreat`；独立试玩的原奖励合同保持不变。

## UI 与操作边界

- 战前选择面板保留原有 AI / 本源意识控制选项，并展示任务选择。
- 险地回收必须由玩家接管移动；AI 按钮禁用并给出明确原因。玩家完成回收后仍可交还 AI。
- 战斗 HUD 只增加一条紧凑任务条，不新增大面积文字面板。
- 结算页使用真实回执字段展示 +2 灵石，不在前端自行计算或伪造奖励。
- 安全任务、普通遭遇、其他世界每日行动与存档版本不变。

## 验收

- 奖励单测覆盖撤离、死亡、胜利和未完成目标。
- Engine 集成测试覆盖真实轨迹、任务选择、AI 限制、旧选择过期和重复结算。
- Playwright 覆盖 320×568 的任务选择与 HUD 边界；既有 390×844、430×932 遭遇测试继续执行。
- 文案审查 CSV 与源码保持同步。

本 PR 仅实现 2AG-G 已验证的最小规则与反馈，不扩展新的建筑、技能或任务系统。
