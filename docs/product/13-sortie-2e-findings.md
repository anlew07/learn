# 灵灾出击 2E · 实测发现与产品建议

> 数据基线：2E PR #69 HEAD `0fa5e7366ef232987f305e56c089a7ff91e8adc8`；[GitHub Actions #44031604052](https://github.com/anlew07/learn/actions/runs/44031604052) 全部成功。本文是隔离原型评估，不是正式玩法批准。

## 结论先行

**当前切片证明了“主动走位 + 自动攻击 + 实际拾取 + 双世界日结算”能够形成可运行闭环，但还没有达到值得迁移为正式主循环的平衡质量。**

最明确的方向是保留主动拾取；优先修正技能失衡、难度断层与护灵剑台的低投资回报。正式模拟器入口和旧策略主循环保持不动。

## 关键数据

40 个 seed/危险档，3 个危险档、2 战技、3 操作脚本、2 建设分支。以下胜率均为第二场/首场完整样本的固定脚本胜率，不能解释为真人胜率。

| 初始 D | 站桩 | 绕场避险 | 主动拾取 | 主动拾取碎片/场 | 剑台胜率提升 |
|---:|---:|---:|---:|---:|---:|
| 0 | 0/40 | 40/40 | 40/40 | 约 7.2 | 0 个百分点 |
| 40 | 0/40 | 40/40 | 40/40 | 约 8.0 | 0 个百分点 |
| 75 | 0/40 | 40/40 | 40/40 | 约 8.3–8.4 | 0 个百分点 |

40/40 的 Wilson 95% 胜率区间为 91.2%–100%；0/40 为 0%–8.8%。样本足以揭示当前明显的两极分化，但不足以推断真人胜率或小幅平衡差异。

### 1. 移动是必需的，但当前难度有断层

- 站桩在三个危险档、两种战技下都无法完成出击；平均受击达到生命上限 8 次，未拾取碎片。
- 绕场和主动拾取脚本在全部危险档均 40/40 通关，且平均剩余生命仍约 4.7–6.1。
- D 从 0 提高到 75，没有让主动脚本的胜率下降；现有最后一波 +2/+4 敌人的危险映射不足以形成有意义的难度层次。
- 当前是“完全不动几乎必败 / 合理移动几乎必胜”的二元结果，尚未形成从普通玩家到熟练玩家的渐进挑战。

### 2. 主动拾取值得保留

- 绕场策略不主动追逐掉落，平均约拾取 1.2–2.1 个碎片。
- 主动拾取平均约 7.2–8.4 个碎片，第二场实际可兑换上限 2 灵石通常被触及。
- 主动拾取的平均剩余生命比绕场低约 0.3–1.3 点（随 D/技能变化），但额外带回的资源显著；这是真正能解释“为何要走位接近掉落”的取舍。
- 目前策略脚本会主动追踪掉落且实时规避近身敌人，比普通玩家更聪明，不能把其拾取率/生存率直接作为玩家目标。

### 3. 两个战技缺少平等选择价值

- 驭雷符每场平均实际命中约 2.5–6.28 个目标，伤害反馈可见。
- 聚灵阵纹每场平均触发约 0–0.07 次；当前规则只挡身体接触，而主动移动脚本大多避免身体接触，导致其几乎没有收益。
- 两者在本实验中的胜率差为 0 个百分点；驭雷符平均击退数优势通常只有 0–0.57，防御技能在当前战场条件下也未显著改善胜率。
- 这不是“两个技能已经平衡”，而是**护盾触发条件与当前主要受伤路径/移动方式不匹配**。下一轮应先检查技能合同：护盾是否应抵挡任何一次受击（包括远程投射物），或是否需要提供更稳定的防御收益；再配套下调/调整雷击频率，避免一个技能继续压制另一个。

### 4. 护灵剑台目前不值得 6 灵石

- 同 seed 配对后，建设分支第二场胜率提升在所有危险档、战技与移动策略下均为 0 个百分点。
- 平均击退只增加约 0.05–0.23，剩余生命变化约 -0.30 至 +0.10，拾取碎片变化约 -0.70 至 +0.15。
- 两场后余额比不建设组少约 6.00–6.22，符合实际扣款；但战斗收益几乎不可感知。
- 单发对 2HP 妖狼的理论差异真实存在，但整场大部分结果受雷击、移动和目标分布影响，基础伤害 +1 的收益被稀释。当前不应把“理论上少一击”当成玩家能明显感知的成长。
- 建议下一轮比较：保留 6 成本但强化可见战斗收益；或保留当前效果并显著降低成本。**不要同时大幅降价又加伤害**，否则无法识别是哪项改变带来收益。

### 5. 双世界结算确实发生，但压力持续累积

- 第二世界实际行动率为 100%，不是静态占位。
- 第二日灵灾 D 变化约 +1.66；废土 D 变化约 +1.66 至 +1.71。不同战技/移动策略对这些世界结果几乎没有影响。
- 这证明“出击替代灵灾当日行动、另一世界照常推进”的技术闭环可用；但目前玩家看到的主要是风险继续上升，下一轮需要检查灵灾 D 变化是否有可理解的行动解释，不应伪造每场必然降险或跨界援助。

## 下一轮建议：2F 隔离数值修正

按优先级建议：

1. **技能公平性**：让聚灵阵纹的防御覆盖真正常见的受伤路径（考虑远程投射物），并配套调整驭雷符频率/目标数量；重新跑同 seed A/B。
2. **难度梯度**：增加 D 档之间的可感知差异；让站桩有明显风险，但不能让简单绕场脚本在所有危险档都无压力 40/40。重点检查妖狼/妖影速度、远程弹道与波次密度，不要只堆 HP。
3. **建设投资回报**：用配对实验比较“现有伤害 +1 / 更快攻击 / 更低成本”候选，要求玩家能直接观察到收益，同时保留封印资源机会成本。
4. **复验资源循环**：确保拾取能形成有意义的收益，但不能让最优脚本无风险稳定拿满 2 灵石。
5. **体验时长**：自动化可证明 150 秒战斗计时与两次结算，不证明真实玩家 180–300 秒完成。真人测试仍属于独立门禁，不在本报告中伪造。
