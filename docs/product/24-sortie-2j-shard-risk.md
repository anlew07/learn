# 2J-B：碎片掉落空间风险与手机拾取容差（负面实验）

日期：2026-11-18。基线为 2G Draft PR #74 `4187d869998da980d71aa1733deb89398bef5ce3`，独立分支 `experiment/sortie-2j-shard-risk-20261118` 初始与该提交 0 ahead / 0 behind。参照 #74 的 2J 总控合同、已关闭未合并的 PR #79、已集成的 2I-B PR #85 及 `docs/product/22-sortie-2i-pickup-tradeoff.md`。

**裁决：不保留运行时候选，不修改 `src/systems/sortie-sim.js` 或 `src/config/sortie-data.js`。28px 拾取容差、碎片总数、原版奖励/结算和既有战技全部不变。** 本次只增加可复现实验脚本、专属测试和报告，保持独立 Draft PR，不合并。

## 问题、空间基线

2I-B 已以 40 种子、五路线、28/24/20/16px 和有/无预建剑台对照证明：缩小拾取半径主要减少绕场路过时的收获，优秀主动路线仍可拿满 2 灵石，伤害与胜败并不单调；低危绕场首次反馈还明显变迟。因此本轮不再尝试缩半径，也不向拾取直接追加伤害。

2J-B 用同一个源文件的**内存版真实 60Hz 引擎**分析 40 个种子（000–039）× D0/40/75 × thunder/rune × kite/pickup/reverse/short-reverse/drift：1,200 个原版战斗，无伪造碰撞。基线生成的 9,722 枚碎片中：

| 生成瞬间的空间量 | 数量 | 占全部已生成碎片 |
|---|---:|---:|
| 距任一存活敌人 ≤ 60px | 555 | 5.7% |
| 距任一存活敌人 ≤ 96px | 1,288 | 13.2% |
| 距敌方飞行弹道 ≤ 60px | 1,336 | 13.7% |
| 距玩家 ≤ 28px（可立即捡） | 179 | 1.8% |
| 距玩家 ≤ 40px | 414 | 4.3% |

空间距离取真实击退位置、仍活着的敌人和当 tick 存在的敌方弹道；**不是伤害因果关系**。原版碎片生成位置到最近存活敌人距离的中位数约 157px，到玩家约 75px；敌群与掉落区通常已分离。自动拾取脚本会追逐最近掉落，同时在 64px 内避让敌人，轻易取得绝大多数资源。因此不能把「原本更近敌人」当作能增加受击的充分条件。

## 唯一候选（仅内存）

候选名：`drift-to-living-enemy-48px`。

每次达到 **每击退 3 敌人生成 1 枚碎片**的原条件时，把新碎片坐标沿向最近**仍存活**敌人的方向平移，距离为 `min(48px, 最近敌人距离 / 2)`，并限制在战场边缘内。没有存活敌人或重合时保持原掉落坐标。方向完全确定，不消耗随机数，不改变敌人、伤害、攻击、拾取半径、碎片转换率或奖励上限。机制只用于分析「更靠敌群是否自动形成危险代价」，尚未证明适合游戏观感。

候选复制并仪表化原 `src/systems/sortie-sim.js`；原版复制仅添加同样的只读观察信息，确保比较不依赖另写一套战斗算法。生产源码未修改。实验复用 2I-B 的 `pickupRouteInput`、现有战技暂停规则和 `previewSortieRewards`。

## 40 固定种子配对结果

控制组和候选组分别 1,200 场，共 **2,400 场真实 fixed-tick 引擎战斗**；每个「危险×技能×路线」单元 **40 对**，无预建剑台。两组产出的碎片总数可以因走位/击退轨迹变化而不同，但各场严格符合 `生成 = 已拾取 + 尚未拾取 = floor(击退 / 3)`。

候选碎片生成时距敌人 ≤60px 的数量由 **555/9,722（5.7%）→1,547/9,710（15.9%）**，近弹道 ≤60px 由 **1,336→1,577**。但是玩家 ≤28px 的出生碎片由 **179→752**，这种空间迁移同时大量提高了**不主动拾取就捡到**的机会。

### 首次拾取反馈与真实碰撞

原版 → 候选：D75 纹主动平均首次反馈 **15.28s→约 15.3s**（40/40 均有反馈），平均受击 2.475→2.675，但仍拿满 2 碎片灵石。D75 纹绕场首次反馈 **28.83s→26.9s**（有反馈 37→39/40），平均受击完全不变，反而额外获得碎片灵石 0.225。

高危雷的长反向路线受击 4.575→4.175，短反向却 4.250→4.400，说明与敌弹、碰撞无敌帧和追逐路径的交互**不是单调风险提升**。候选造成更多「靠近敌人的拾取」只是代理量升高，不能等同玩家遭受了更可理解的伤害或选择困难。

## 产品裁决

**拒绝此候选，保持 28px 原规则不变。**

1. 最大 48px 向活敌偏移虽然提高附近敌人的暴露比例，却意外增加被动绕场拾取；反而削弱资源路线的独立价值。
2. 高危纹主动拾取平均真实受击仅 +0.20，胜场和碎片灵石没有变化；中低危以及误操作脚本没有稳定、单调的风险/收益曲线。
3. 40 固定种子能比较工程机制，不足以证明移动端玩家能感知掉落的物理直觉；让碎片向存活敌人移动还可能违背死亡位置掉落的用户预期。
4. 更根本的限制是「活敌与碎片通常分离 + 自动路线追碎片很精准 + 2 灵石奖励很容易达到上限」。继续只调整空间偏移系数没有足够依据。建议总控下阶段从敌群追击节奏、奖励上限及路线反馈的**设计层**作统一评估，不在 2J-B 越界改这些系统。
