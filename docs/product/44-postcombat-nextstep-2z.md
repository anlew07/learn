# 2Z · 战后下一步（真实战报到策略决策）

> 基线：`main@f2fd7a9`，2Y 已验收合并。不是新战斗系统或独立模式。

## 玩家问题

正式世界已有自动战斗回顾和真实战术支援，但玩家读完战报后仍需要自己寻找对应的下一步操作；战报、战术、策略之间缺乏连续的可玩路径。

## 本次实施

- 只在**上一日确认发生的正式自动战斗**战报内，显示简短的“战后下一步”；不会加主屏信息框。
- 存在关键事件或战技选择时优先进入原有待处理面板，避免引导玩家忽略暂停决策。
- 已布置 2X 集中火力时，指向查看待命战术，避免暗示重复购买。
- 已全退敌群时，优先查看世界行动策略；有敌群未击退且战术可用时，可预览下一场 1 AP 战术；支援不可用时则查看策略。
- 如果上次战斗曾实际消耗战术，回显权威引擎提供的新增击退和实际减灾；没有真实回执则不造数据。
- 点击入口**只打开原有面板，不自动消费 AP 或更改自主行动**。新入口会随世界、日历、事件状态重新由纯展示函数计算，不写存档。

## 复用、性能和规则边界

复用 `getRecentEncounter`、`pendingDecisions`、`Engine.previewTactic`、`scene-panel` 事件委托以及正式战报；不引入第三方库，包体影响仅是少量展示函数/CSS。旧存档、暂停和多标签只读行为沿用现有边界。跟随《Loop Hero》的间接干预思路，但不复制玩法和素材。

## 验收

- Vitest：部分击退、全部击退、待选事件、支援待命、缺 AP、陈旧/结束战斗、权威差额、10 次只读。
- Playwright：320×568、390×844、430×932，真实 Engine 自动遭遇结算后，实际触摸“场景战报 → 下一步”并检查对应原有面板与 ≥44px 目标。
- CI lint / format / text:check / Vitest / build / 数值 / Playwright。
- 尚未证明玩家真实理解度；不是实时可操控战斗，也未新增奖励或经济规则。
