# 提审 / 上线门禁（按优先顺序）

此清单为可执行验收项，不代表当前项目已完成或取得平台许可。

## P0 · 内容审核与文本

- [x] 初次对照 TapTap 官方规范核验风险点。
- [x] 首批玩家可见用词以守护、救援、恢复秩序为主进行改写；未调整玩法与稳定存档 ID。
- [x] 建立可重复导出的静态文本候选 CSV 与 CI 同步检查。
- [ ] **人工**逐条审核所有静态中文片段，剔除注释和技术代码。
- [ ] **人工**补全动态拼接、变量文案、旧档历史日志与实际截图里的全文字句。
- [ ] 形成无代码的最终 Word/Excel 文本，逐句校对与真实游戏一致。
- [ ] 根据所选发行地区核实版号、资质、年龄分级及是否要走敏感题材深度审核工单。

## P1 · 快速开局

- [ ] 首次体验仅聚焦一个世界 / 一个分身 / 一个主要目标，进阶模式入口仍可直接选择。
- [ ] 3–5 分钟完整决策—结算—成长小循环：真实手机计时验证，不是仅凭模拟预计。
- [ ] 首次接触援助、事件、战技时给一两句话情境提示；不改变正式引擎结局资格。

## P2 · 真机与浏览器稳定

- [ ] Android Chrome 在 HTTPS 上完成新局、存档、刷新/后台恢复、弹窗和触控测试。
- [ ] iOS Safari 在 HTTPS 上完成同样操作，并验证 Web Locks 不可用时的只读/接管提示。
- [ ] 对 HTTP 局域网、无痕模式、拒绝存储、额度不足、双标签并发确认行为与故障提示。
- [ ] 使用实际低端手机检查动画、长时间运行、竖屏滚动以及横向溢出。

## P3 · 数值与基础引导

- [ ] P（救援准备）、D（危机压力）、AP（行动点）、材料与灵魂强度的解释都可在首次关键操作处看到。
- [ ] 固定种子 A/B 对照，不将自动模拟的拯救率写成真人测试数据。
- [ ] 对首局随机过早失败、异常无解、进阶内容过早曝光设计回归用例。

## P4 · 广告最小闭环（**暂缓**）

- [ ] 核实实际发行环境支持的官方激励广告接口及收益/政策条件。
- [ ] 只在真实广告完成回调后，发放一次奖励并写入存档。
- [ ] 广告关闭、未加载、播放失败及重复回调不会扣费或重复发奖。
- [ ] 不强制观看、不伪装系统提示、不在后台展示广告。

## P5 · 物料与资质

- [ ] 开发者认证、主体资格、适用游戏资质、发行地区规则核验。
- [ ] 真实游戏 icon、截图、演示视频、名称和安装包名称一致性。
- [ ] 隐私政策与第三方 SDK/数据处理情况准确一致。
- [ ] AI 生成内容与相关素材授权/使用证明按实际来源整理。
- [ ] 提审文本、审核包/可达全流程入口及截图证据归档。
