# TapTap 商店页资料 · 审核候选（未提交平台）

> 项目工作名：《同时穿越·末日模拟器》；商店候选展示名：《同时穿越：多世界救援计划》。**二者是否统一必须由发行主体确认，本 PR 不修改游戏名或代码。** 以下是策划草稿，素材、字数限制和敏感题材最终以 H5 小游戏后台审核为准。

## 推荐一句话介绍（候选）

一个灵魂，联结多个危机中的世界；让分身自主探索和成长，用有限行动点决定支援、救援与重建的时机。

## 短简介（候选）

当灵脉异动、废土失序与异兽迁徙同时发生，三个世界的命运开始交织。分身会自主行动，你负责观察资源、选择策略、处理重大事件，在有限的时间里守护更多生命与家园。未知灾变从何而来，还等待探索。

## 详细简介（候选）

同一个灵魂可以连接不同世界的自己。分身各自探索、训练、收集材料并推进救援；世界也会随时间发生变化。你不需要每秒操作，但每次主动支援都要权衡行动点、资源、危机压力与其他世界的机会成本。

在三条各有难点的世界线中，发现异变线索、准备关键事件，尝试组织防线、恢复秩序。你可以观察自主策略，也能在时机成熟时派出援助，组合战技并回顾三波自动战斗的结果。

即使准备充分，危机也不会自动消失。成功需要满足实际主线和资源条件；失败有真实代价。故事不会预先宣布一个掌控全部灾变的幕后反派，探索仍将继续。

## 可据当前原型确认的核心特色

- **多世界独立演化：** 世界分支各自推进，主线与挑战并不完全相同。
- **有限资源的关键决策：** 救援准备、危机压力与行动点构成取舍。
- **跨世界援助：** 支援既有实际收益，也可能减少来源世界的终局材料。
- **自动战斗构筑：** 通过三波结算和战技选项回顾结果，**不是自由走位的即时动作游戏**。
- **成长与未知事件：** 闭关、材料、线索和隐藏彩蛋使局内发展具有变化。
- **轻量网页体验：** 当前使用浏览器本地存档与暂停；**不承诺 TapTap 账号/跨设备云存档已完成**。

## 开发者的话（候选）

我们希望把紧张的生存挑战与协作决策放在同一个游戏里。面对未知的灾变，玩家能看到每个分身做出的努力，也能判断何时出手帮助另一处世界。游戏目前处于迭代中的 H5 原型阶段，欢迎反馈节奏、策略反馈与手机操作体验。

## 禁止作为已实装宣传的表达

- 不把三波自动结算描述为《吸血鬼幸存者》式自由走位、实时躲避或完整弹幕动作。
- 不宣传尚未接入的 TapTap 登录、账号同步、云存档、广告或付费能力。
- 不宣传所有世界均可挂机保证获救，不保证每局结果一致，也不将自动种子模拟数据称为玩家胜率。
- 不把某一个兽王、感染源或首领确定为全部末日的唯一幕后主使。
- 不用尚未实装的美术概念图冒充当前像素风 H5 的实机画面。
