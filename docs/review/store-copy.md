# 商店页文案草案 · 待人工审阅

**候选展示名：** 同时穿越：多世界救援计划

**一句话介绍：** 一个灵魂，联结数个世界；派出分身组织救援，用策略与协作守护家园。

## 短简介

在灵脉异动、废土危机与生态失衡的世界之间同时行动。分身负责日常成长和探索，你用有限的灵魂行动点作出关键决策：调查线索、支援伙伴、稳住防线，让更多世界迎来恢复秩序的明天。

## 详细简介

当多个世界同时出现异常，同一个灵魂可以与不同世界的自己相互联结。每位分身都能自主探索、训练和筹备救援；你则在关键时刻决定是否介入。管理有限的行动点、材料与灵魂强度，寻找最适合当前危机的解决方法。

**并行模拟：** 不同世界独立演化，也可以共享重要经验与支援机会。

**策略救援：** 观察危机压力、救援准备与时间限制，在成长、探索、守护和援助之间取舍。

**战技构筑：** 可选的三波防线行动与战技组合，带来不同的克制与防线协同效果；战斗以简化的数字与抽象符号呈现。

**轻量体验：** 支持浏览器内存档与暂停；分身会自动推进，你可以按自己的节奏参与决策。

游戏为持续完善中的 H5 原型，部分玩法、画面与体验仍在调整；具体上线版本请以商店可玩的实际内容为准。

## 开发者的话（与玩法简介区分）

希望做一款让玩家感受“危机中有人互相帮助”的多世界策略游戏。相比单纯追求更大的伤害数字，我们更关心每个决定会如何帮助另一个世界。欢迎反馈文字可读性、救援目标是否清楚，以及手机上的实际操作体验。
