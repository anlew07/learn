# TapTap 文案提审工作区 · 2026-11-13

> **提审草稿，不是平台审核通过证明。** 所有文字和素材最终必须经过开发者人工逐条复核，并以拟上架地区、游戏类别和官方最新要求为准。

## 官方依据（提审前再次核对）

- [TapTap 游戏审核规范细则](https://developer.taptap.cn/docs/store/release/publish/agree/)：游戏本体及商店物料不得含血腥暴力等敏感内容；物料必须与游戏实际内容一致。
- [新建和管理游戏 · 敏感题材文本提审 FAQ 9.11](https://developer.taptap.cn/docs/store/release/publish/create-game/)：若收到敏感题材深度审核通知，需创建指定分类工单；**文本须包含游戏内所有文字，可使用 Word/Excel，确保每字每句能在文档中搜索到**；部分项目还需完整流程的审核包。页面说明的处理时间约 5–7 个工作日，仅供排期参考。

平台没有承诺替换几个关键词就能通过。文案表达优先突出**组织救援、维持生存、恢复秩序**，但剧情可保留真实失败后果，不应误导玩家。

## 已生成的候选文本

- [game-text.csv](./game-text.csv)：Excel 可打开的 UTF-8 BOM CSV；覆盖当前 `index.html` 和 `src/**` 下 JS/CSS/HTML/SVG 中每一条包含汉字的源码行，并附带少量英文界面词。
- CSV 包含源码文件、行号、需人工复原的动态拼接提示、敏感词提示和完整源码片段。**这只是保守的全文本候选扫描，不是已审定可直接提交的最终稿**：含有内部注释、语法和 HTML 片段，且动态数字、变量与拼接后的完整句子需要人工整理。
- 新增或修改任何运行时文案后执行 `npm run text:export`；CI 用 `npm run text:check` 防止忘记更新静态候选清单。
- [store-copy.md](./store-copy.md)：较温和的商店简介与开发者的话草案，尚未提交 TapTap。
- [launch-checklist.md](./launch-checklist.md)：从内容、体验、真机、广告到资质的上线门禁。

## 新增：动态句式候选导出

静态行级导出不能将 `"第" + day + "天"` 自动还原为玩家看到的句子。运行 `npm run text:runtime` 会在本地生成 `docs/review/runtime-templates.csv`；`node scripts/export-runtime-templates.mjs --stdout` 可直接输出到标准输出，便于审核人员处理。**CI 也会运行导出器，并在每次验证流程中附上可下载的 `runtime-text-review` 工件（保留 14 天）**，不依赖手工执行才能拿到候选表。

此表基于现有 ESLint 解析器收集 `src/**/*.js` 中的模板字符串和加号拼接，提供起始行、可搜索的中文句式、变量源码表达式、风险提示，并统一标记为“待人工复原”。不需要新增运行时依赖，也不改变存档、事件 ID 或玩法。

**边界：** 这仍不是最终提交稿。`【变量】` 不是真实可见文字；三元分支、`map/join`、函数返回值、DOM HTML 标签、数字格式化、跨文件来源、旧存档的历史日志与隐藏彩蛋可能需要结合实际 UI 重建。候选还可能包括内部字符串。审核人员应对照源码定位和真实游戏截图填入完整运行样例，并保留已复核记录，不得直接将 CI 工件作为平台要求的“游戏全部文字”提交。

## 人工复核流程

1. 在电子表格中按**风险提示**和**动态拼接/需复原**筛选，去除内部变量、测试数据及注释，不要漏掉 `aria-label`、按钮、弹窗和隐蔽彩蛋。
2. 对跨行或 JS 拼接文本，在最终人工稿中写出**运行时可见的完整句子及变量占位示例**，例如「危机压力已达 D[数值]，请查看救援方案」，确保玩家实见文字可以检索。
3. 对 `index.html`、首页、三个世界事件/终局/失败、战技、回放、存档提示、隐私说明、广告提示逐项复核；抽检真机实际显示与文本导出的一致性。
4. 如文字有改动，先更新源码与导出清单，再形成**无代码版 Word/Excel 提审稿**，附游戏版本号、地区及相应的全流程审核方式。
5. 检查未完成的商店截图、icon、视频、资质，确保商店素材与真实游戏一致，不要把概念图冒充实机截图。

## 特别说明

- 保存字段、英文事件 ID、战斗数值和玩家结局资格不因措辞改写而改变；不要为审核临时隐藏玩法或搞提审/上线两套内容。
- 旧存档里可能保留修改前的历史日志、已完成事件标题或战斗记录；正式提审须使用全新档及旧档恢复做双向验证。若需一键导出历史用户记录，须评估隐私与数据结构。
- 真机 Safari/Android、HTTP 非安全上下文、无痕/存储失败尚未完整验收，不能以桌面 Chromium 模拟视口代替。
