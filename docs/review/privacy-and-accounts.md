## 适用于当前浏览器原型的隐私说明要点（非已发布政策）

- 说明存档是否只保存在当前浏览器设备，卸载、清理浏览器数据或更换平台域名可能导致存档不可访问。
- 如后续接入平台登录、广告、埋点、云存档或第三方 SDK，应在功能上线前更新用户可见隐私说明，核对第三方共享、收集目的、存储期限与用户权利。
- 不声称已采用端到端加密、跨设备同步或提供数据删除后台；如未实现，不得做宣传承诺。
- 需要根据最终运营主体与发布地区，确定准确的隐私政策/联系人/适龄提示。此文档只列待填写项，不代替正式法律文本。

## 发布前的人工确认顺序

1. 认证 TapTap 开发者主体，选择 H5 发行方式；保留官方后台状态，不将账号密钥放进代码。
2. 检查前置备案、游戏权属、付费/广告、未成年人保护和特殊题材流程对 H5 的适用性；有分歧通过官方工单确认。
3. 平台授权上传候选 `dist`，使用平台测试入口验证 IndexedDB / Web Locks / 刷新后台恢复与资源相对路径。
4. 整理实际玩家全文本和截图、真实隐私说明；通过平台实际审核后再标记「发布」。
