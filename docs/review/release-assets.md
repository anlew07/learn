## 截图建议内容（均须真实运行后录制）

1. 竖屏世界卡和像素风三世界状态（体现并行模拟）。
2. 资源紧张时的重大事件预览、成功率、费用与代价。
3. 自动三波战报及构筑回显；如果仍是文字+抽象图标，必须如实呈现。
4. 跨世界援助实际支付前预览与获救/失败反馈；第 4 张只在平台允许附加截图时使用。

## 物料提审前检查

- [ ] 命名、图标、短简介、实际首页标题一致，且不暗示「已过审」。
- [ ] 图中无其他平台水印；不使用纯概念图隐藏真实游戏 UI，不包含虚假功能。
- [ ] 全部像素美术来源、生成工具、许可/授权链和修改记录有归档。
- [ ] 文件尺寸/方向/体积在 H5 开发者后台校验通过；截图和录像来自实际测试版本并记录版本号。
- [ ] 对比主线最终发布版本，避免 PR 合并后截图和游戏文字不同步。
