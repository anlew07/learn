# 灵灾世界 · 内容框架

**定位：** 修仙末日世界。灵脉失控、妖兽变异，分身修炼突破，在末日到来前找到并封印灵灾核心。

## 五类通用行为

| 类别 | 灵灾表现 |
| --- | --- |
| 成长 | 吸纳灵气、普通修炼 |
| 采集 | 寻找灵石 |
| 战斗 | 清剿妖兽、讨伐巢穴 |
| 探索 | 调查灵脉、探索遗迹 |
| 拯救 | 调查阵眼、准备封印、最终镇压 |

## 成长

练气 Lv1 → 筑基 Lv2 → 金丹 Lv3 → 元婴 Lv4。首版普通境界突破在经验条件满足后自动成功；大机缘、提前突破和特殊能力才具有随机性。成长优先容易获得静修经历，探索/清剿容易获得战斗与古阵经历，但不设置不可逆职业锁。

日常修炼提供基础经验，不强制消耗灵石；强化修炼和最终封印可消耗资源。分身具有目标资源预留意识，防止随意耗尽封印所需灵石。

## 专属机制：闭关

筑基后开放。安排次日开始，预留 1 AP；短/长闭关暂定4/6日，分别提高修炼效率；闭关期间不执行普通探索、清剿、拯救，世界灵灾和其他世界继续。正常完成释放 AP，事故只判定一次；强行出关需额外惩罚且可重复提交保护。闭关期间不得作为力量叠加提供者。

详细第一包：[修炼内容包](../../content/packages/lingzai/01-cultivation.md)。

## 妖兽生态

普通妖兽通过行动/事件生成；持续妖兽巢穴和灵气泄漏使用共享的 Threat 模板，活跃时每日增加世界压力。首版同时最多2个普通活跃威胁；清理后压力停止，但毁灭进度不会凭空归零。不要开发逐只妖兽 AI。

详细规则：[妖兽内容包 02 · 妖兽生态与狩猎](../../content/packages/lingzai/02-beasts.md)（设计稿，数值待测）。

首批敌人：裂纹妖狼（Lv1）、腐灵山猿（Lv2）、裂脉狼王（精英 Lv3）。裂纹狼巢是一处持久威胁：需多日清剿外围，进展足够后排队触发首领事件；自动实力不足时谨慎撤退，成功清除后停止持续压力。狼王可提供可选灵脉线索，但不构成普通封印主线的唯一入口。

## 主线与结局

1. 调查灵气异变，发现灾源。
2. 找到灵脉核心与阵眼。
3. 累积修为和封印资源，完成准备。
4. 执行最终封印，世界尚未毁灭时才能拯救。

常规调查可在无稀有机缘的情况下推进 P30（确认灵灾）→ P65（定位阵眼）→ P100（完成封印准备）。三个里程碑只写剧情标记与解锁、不重复加 P。金丹 Lv3 是基础资格。标准封印候选灵石10，拥有古阵认知可用灵石7进行辅助封印；**两者均不强制 Boss 战**。狼王线索仅增加可选调查捷径，不是主线钥匙。

详见 [灵灾内容包 03 · 探索与灵脉封印](../../content/packages/lingzai/03-exploration-seal.md)，数值仍待测试。

## 样板经历链

探索雾谷 → 发现古碑 → 稳妥研究/强行激活 → 留下古阵认知或灾害风险 → 后续封印阶段按标记显示新方案。没有古碑也可走普通路线。

## 联动

重大突破可以分享成长记忆。作为提供者可帮助尸潮/兽潮战斗，但闭关时不能借力。拯救成功后一次性回响暂定为其他运行世界降低毁灭进度。
