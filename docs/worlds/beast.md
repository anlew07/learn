# 兽潮世界 · 内容框架

**定位：** 猎杀异兽、吸收结晶、不断进化；兽王也随末日时间不断变强。突出“趁早冒险还是继续成长”的取舍。

## 五类行为

成长（吸收进化结晶/强化身体）、采集（寻找结晶）、战斗（狩猎与清理兽群）、探索（追踪迁徙和兽王）、拯救（寻找变异源、最终讨伐）。

## 成长

Lv1 普通猎人 → Lv2 强化者 → Lv3 超凡猎人 → Lv4 进化领主。普通/精英/高危狩猎收益风险不同；弱小猎物经验衰减，首次精英狩猎特殊奖励每局不可重复刷取。通过“巨兽之力”“追踪感悟”等经历形成路线，不必立即设计完整进化树。

## 专属机制：兽王演化

兽王苏醒 → 进化 → 狂化，主要由世界阶段、活跃兽群和重要事件决定，不直接随分身等级变化。进入终战时仍活跃的兽群可能强化兽王；清除兽群则可降低难度。不要单独展示“兽王进化值”进度条。

异兽巢群沿用持续威胁节点结构，保持最多两处普通活跃威胁。

## 分支与终局

巨兽足迹 → 深入追踪/调查外围 → 获得不同调查经历 → 找到变异源 → 终局准备。常规基础路线不依赖稀有机缘。

最终基础资格暂定 Lv3、变异源线索、足够进化结晶（旧候选14）。当前兽王可能需要 Lv4 或 Lv5 有效战斗等级。二人之力+1、三人之力+2可用于合力挑战，但基础资格/材料不能绕过。P100不是自动成功；终战条件不足时继续准备，不要立即自动失败。
