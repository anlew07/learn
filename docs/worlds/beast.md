# 兽潮世界 · 内容框架

**定位：** 猎杀异兽、收集进化结晶、积累特殊经历，面对不断进化的兽王。详细内容包见 [兽潮内容包01](../../content/packages/beast/01-evolution-hunt.md)。

## 五类行为

成长（稳妥训练或R2吸收结晶）、采集（搜寻结晶）、战斗（普通狩猎/清巢）、探索（追踪变异源与巨兽足迹）、拯救（终战准备与压制兽王）。每天一个主要行动，旧版固定策略收益不能重复叠加。

## 成长与特色

Lv1普通猎人 → Lv2强化者 → Lv3超凡猎人 → Lv4进化领主。Lv3是终局**实际等级资格**，Lv4具备标准Lv4兽王的独立战斗实力；灵魂借力只能补**本次**战斗等级，不替代资格。普通训练不耗结晶，强化吸收需要R且有更高XP。

普通/高危狩猎分层；实力不足时自主撤退而不盲目送死。可选巨兽足迹事件与精英经历增强故事差异，但不为必需前置。

## 持续威胁与兽王演化

赤角兽群采用通用威胁节点，清除后停止每日额外D。兽王分苏醒、进化、狂化三阶段，时间独立于分身等级；当前终战战力要求通常Lv4，有活跃兽群或狂化时提高至Lv5，**最多Lv5，不堆成Lv6**。

## 可靠的独立通关路线

普通调查达到P30/65/100，不依赖任何随机巨兽足迹或精英事件；实际Lv3+、R14候选。若兽王后期升至Lv5，分身可通过P65后**两次非随机抑制行动**（第二次耗R4）将本局战斗要求降低到最低Lv4，再由实际Lv4独自讨伐。P100时不自动无脑攻击无法胜利的兽王。

二人/三人之力可以帮助提前挑战，但不应成为唯一通关方式；成功后只生成一次兽潮回响（暂定目标XP+8）。

**具体数值、回合耗时与胜率均未实际测试。**

## 已实现 · 足迹后续「围猎路线」

高风险巨兽足迹调查成功后且P65达成触发一次。免费整理路线至多P+2；花1AP和3进化结晶可将兽王压制至少提升至第二阶段、当场D−2。狂化兽王需求仍用原公式在Lv4与Lv5之间计算，不能绕过实际Lv3/最终材料条件；已有二阶压制不能重复付费。
