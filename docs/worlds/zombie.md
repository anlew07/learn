# 尸潮世界 · 内容框架

**定位：** 废土生存与感染母巢；核心取舍是材料用于防线还是最终净化。当前详细规格见 [尸潮内容包01](../../content/packages/zombie/01-survival-mothernest.md)。

## 成长与行动

Lv1 幸存者 → Lv2 猎杀者 → Lv3 清剿者 → Lv4 末日猎手。五类主要行动映射：训练、搜刮、清剿感染体、调查信号、净化准备。每游戏日只有一个主要行动。实际 Lv3 是终局资格，Lv4 可独立通过常规母巢守卫 Lv4；也可用已解锁的二人之力补一次战斗等级。

## 资源与专属机制

废土零件既用于安全区大修（候选 R6、D-12、每局一次）也用于最终母巢净化（候选 R12）。大修属于当日主要行动；正常情况下留足终局资源，D≥85时允许优先自救。这些阈值均待模拟与平衡。

## 生态与经历

游荡感染者、装甲感染者、停车场暴走体是首批敌人。地下停车场尸群属于共享 Threat 模板，多日清剿、排队精英战、清除后停止持续压力。失联广播为可选探索事件，可解锁后续研究捷径或守卫弱点；没触发广播也不能卡住主线。

## 常规拯救主线

P30 确认异常感染模式 → P65 定位母巢 → P100 准备完成 → 检查实际 Lv≥3、足够零件和有效战斗等级 → 一次性净化母巢。P100 不是世界获救；战力不足时自动训练而不是每天送死。晋升到 Lv4 可独立过关，可选守卫弱点或二人之力让 Lv3 提前挑战。

## 设计边界

不加入居民数、食物、弹药、耐久、士气等额外常驻条；世界自主运行、事件自动选项、记忆共享和安全存档都使用通用引擎。事件、敌人和数值均为设计稿，未经过程序测试。
