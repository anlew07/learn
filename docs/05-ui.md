# 05 · TapTap H5 竖屏交互

## 核心五界面

1. 首页：开始/继续、局外成长、存档入口。
2. 模拟主界面：全局日期、灵魂、AP、速度、暂停、三个世界状态卡、紧急事件、近期战报。
3. 世界详情：成长、拯救、经历三个标签；策略、资源、状态、专属机制。
4. 结算：每世界结局、关键经历、碎片、下一次模拟。
5. 局外成长：永久升级、解锁世界、天赋。

顶部固定全局状态，底部保留世界/事件/灵魂/日志入口。主界面纵向排列世界卡，每卡展示 P、D、剩余时间、当前行动及风险；重要详情可展开。

## 重大事件

列表按紧迫程度排序。进入详情时临时冻结模拟计时；关闭后恢复先前是否暂停的状态。呈现自动处理结果、手动选项与成本、剩余处理游戏日。按钮条件不足时显示原因。没有处理的事件照样按到期规则自动执行。

## 万我同源

在“灵魂”面板显示记忆记录、资源援助、二人/三人之力和世界回响。资源援助流程为：选择来源 → 目标 → 效果 → 显示完整成本 → 确认。借力必须说明来源世界后续虚弱。结果显示具体前后数字和一段短战报。

## 文字反馈与可读性

常规日志合并，突破/机缘单独突出，世界危机与结局置顶。玩家始终能看见当前目标、缺什么材料、为什么进度已满仍无法拯救。

设计目标：正文字号 15–16px、主要按钮高度至少 44px、手机宽 320–430 CSS px、无横向滚动、底部安全区域适配；这些不是平台强制标准。

## 新手

第一次固定灵灾+尸潮双世界。第一次事件或援助可分步引导，其余模拟仍自动运行。第二局开放二人之力，第三局加入兽潮三世界及三人之力。教学可跳过，不强制玩家点击每日行动。
