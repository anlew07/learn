## 3. 定位机制与为什么没有继续提高收益

旧规则：第三局救援优先兽潮平均探索 **20.00 天**、准备 **8.37 天**、成长 **18.05 天**、压制 **1.69 天**、排险 **0 天**，结果 **81%** 以危机进度 100% 结束。它较早达成 P100，后期还要补等级、材料和战斗资格。

两次排险既占用真实主要行动，也能依照原有规则推进活跃巢穴的精英战；成功时精英原本就会发放 XP+8 / R+3 / P+3 / D-5 并消除持续巢穴压力。原版救援偏好从不考虑该路线，错过了已有的成长—材料—战斗—减灾循环。

这次**不调整**日常自然危机、产出倍率、兽王终局费用、精英奖励、合成概率及波次奖励。只在 `beast` 世界的 `rescue` 偏好、Lv≥3、P≥65、D≥93、有可处理的活跃巢穴、且并非显然已满足终局条件时，将两个真正的主要行动投入巢穴外围排险，然后依照既有队列处理精英与风险。其他策略不自动变成排险优先。特别注意兽潮世界默认策略本来就是 rescue，因此全局 default 组合的兽潮也会受到影响。

## 4. 战斗构筑、精英克制与资源经营

- **三波战斗不增加主行动。** 每次 `fight` 只有一个主要动作、一次聚合战斗收益；`meanWaveBattles ≤ meanFights`、XP/R/减灾上限由既有回归测试约束。
- **同一批 100 种子的开启战潮对比**：第三局救援优先兽潮由未调整的 **19%** 提升到候选 **49%**（关闭战潮候选 **40%**）；默认由 38% 到 66%（关闭战潮候选61%）。这一差异说明救援偏好真实参与战斗后，构筑奖励终于有机会影响最终结果，不是 UI 战报装饰。
- **额外 60 同种子对照**：救援候选关闭战潮 38.3%、开启战潮 50.0%；启用战潮后的每局兽潮平均完成 **1.8** 次波次战斗、额外 XP **0.90**、结晶 **0.45**、D 减少 **0.27**。这只是通过已有奖励上限的实际结算，不构成第二次战利品。
- **精英反制与终极技能**：兽潮完整的「裂爪连击＋追猎直觉」进化可以使用 `hunt` 连携反制装甲/迅捷波次。修复了旧实现仅凭 `build.evolved=true` 就给波次基础战力 +6、并可判断进化清屏的边界；现在必须能以真实装备组合触发已有终极技能。仅伪造进化标记不能增强波次战力，也不能绕过实际 Lv、主线或材料资格。
- **经营与战斗仍有不对称**：旧清剿偏好第三局兽潮平均约 17 次排险，虽积累经验/材料，却要承担更多主要行动的主线拖延；成长优先资源更少但战力较快。当前大量自动获得的战技在「成长/救援」路线仍因未战斗而缺乏出场；后续应独立评估战技选择与资源保留的主动操作，而不是再次直接增加被动战斗收益。
- **战斗资源依赖**：资源经营通过结晶储备限制兽潮压制与终战；排险通过正常战斗与精英收益补结晶和 XP，打断既有「补级→采集→终战」的单一路线。装备选择本身当前不扣资源；本阶段没有私自引入新的武器强化费用或存档字段。

## 5. 跨世界援助与融合漏洞复查

复核 `src/systems/aid-contract.js`、`fusion-contract.js`、`src/engine.js` 与已有 Vitest/干预脚本：

- 资源援助必须从仍在运行的来源世界支付 **R4 + AP1 + 灵魂1**，目标每次 P+12 或 D-12 均按实际缺口截断，且两模式共享目标的完整日冷却；不会免费转移物品或绕过源世界材料风险提示。
- 融合必须存在合法首领/终局资格、足量供力者和足量 AP/灵魂，使用后供力者 3 日虚弱并进入融合冷却；不能绕过 P100、实际基础等级或最终结晶。已结束世界不能作普通来源。
- 重放同一 `operationId` 时不重复支出和奖励，事件结算和回响使用沿用既有一次性标记；`npm run compare:interventions:check` 与相关 Vitest 已通过。本轮**没有发现必须改这些合同的无成本套利**，没有因此修改存储、UI 和跨世界合同。

## 6. 结论、限制及下一步

本轮保留高风险清巢优先级（D≥93）；不再单纯抬升直接救援收益。第三局兽潮仍有 39%（默认）或 60%（全救援策略）D100 失败，救援并未成为无脑稳赢。**但**默认兽潮获救率 61% 已略高于成长 55%，阈值对结果敏感；应使用更多种子、真实玩家操作和存档恢复回归后，再决定是否作为正式平衡值。

其他需单独解决的问题：第二局废土救援/成长获救率仅 17%；第一局灵灾四策略均 100%，策略差异不足；可选战潮在部分非战斗策略里存在「已进化却基本没有出战」的问题。

这些是固定脚本策略下的结局对照，**不是**真实玩家胜率、真机体验或 TapTap 审核承诺。PR 保持独立，不自动合并主线。
