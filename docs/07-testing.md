# 07 · 测试与数值平衡

## 状态声明

**以下是计划，不是已运行的测试结果。** 过去对经验、毁灭曲线、100 日通关时点的手算属于示意，存在与公式不一致的风险；不可引用为验收数据。

## 基础规则测试

| 场景 | 预期 |
| --- | --- |
| 完全不操作 | 各世界仍成长并最终得到结局 |
| 分身闭关 | 本世界普通行动停止，外部世界和灾源继续 |
| 没有足够资源 | 行动整体拒绝，不先扣 AP |
| 到期未处理事件 | 恰好自动结算一次 |
| 玩家已处理事件 | 到期不再执行自动结果 |
| 清除威胁节点 | 此节点停止每日压力，不擦除历史毁灭 |
| P 达到 100 但缺材料 | 进入准备而非直接获胜 |
| 终局战条件不足 | 自主准备，不每天反复送死 |
| 记忆共享引发升级 | 不触发无限共享 |
| 二人/三人之力 | 临时战斗加成、虚弱及冷却正确 |
| 灵魂归零 | 未结束世界按规则终结 |
| 存档恢复 | 同步恢复事件、冷却、闭关和随机流 |
| 重复提交指令 | 无双倍扣费/奖励 |
| 更新数值配置 | 有清楚的当前局处理策略 |

## 战斗与持续威胁专项计划

- Lv1 遇 Lv2 普通妖兽：自主避战或执行合法保底行为；被迫交战需显示失败结果。
- 清巢行为与普通巡猎绝不在同一天领取双份行动奖励。
- 轻伤会使有效战斗等级下降；支付前若必败则拒绝强化操作，不扣 AP/灵石。
- 巢穴清剿进展 0/2→1/2→2/2，随后首领排队仅一次、不覆盖其他重大事件。
- Lv3 自动击败 Lv3 狼王；Lv2 可通过合法灵石强化或二人之力补足战力（互斥）。
- 主动撤退/自动撤退后巢穴继续施压，重试冷却满四个完整游戏日才能再挑战。
- 首领清除巢穴当天不加该节点日压力；自然恶化仍结算。
- 事件结算、读档、世界崩溃后不会重复发首领奖励、克隆巢穴或重复扣费。
- 不生成狼巢也必须存在可达的常规灵灾封印路线。
- **均为计划测试，没有运行引擎，也没有实际通过率。**

## 灵灾探索与封印专项计划（尚未执行）

- 无古碑、无狼巢：普通调查仍可推进 P30/65/100，金丹与灵石10后可标准封印。
- 一次性从 P28→70：顺序触发30和65里程碑，只登记标记，不重复加 P。
- P65但等级不足，核心地点可按主线开放，高阶战斗仍受实力限制。
- 狼王/古碑同时被发现：一个待处理重大事件，其余只排队一次。
- 古碑不处理：稳妥研究自动结算；手动激活判定只抽一次并保存。
- 狼王线索追踪一日仅有一种主要行动收益，不叠加普通调查奖励。
- P100但 Lv2、灵石不足或正在闭关：不可封印，分身继续处理缺口。
- 无古阵 R10可成功标准封印；有古阵 R7可成功辅助封印。
- 达到 D100立即崩溃；截止日日终前完成封印算成功。
- 封印费用、世界回响和成功标记均不可因刷新与重复指令再次结算。

## 数值测试策略

未来使用**正式引擎**跑固定种子与多种自动策略：全成长、全清剿、全拯救、均衡、集中援助、很少人工干预。每策略至少先 100 局，后来扩至 1000 局，记录拯救率、平均天数、崩溃原因、AP 消耗、灵魂消耗、事件出现频率、各世界独有机制使用率。

目标：既不存在稳定必胜的单一策略，也不能绝大多数新手局在学会操作前就必败。

## 暂定平衡参数（绝非定稿）

- 20 秒/日，1×/2×/4×。
- 首局 15–25 分钟；普通 30–60 分钟。
- AP 初始2、上限4、8日+2；灵魂初始8。
- 闭关短4/长6日，事故10%/25%，收益倍率1.5/1.8（不同讨论版本，须统一实测）。
- P/D 范围0–100，世界各自有截止日。
- 三人叠加有效战力+2、共用冷却20日、来源3日虚弱。
- 碎片奖励、等级经验门槛、灾源压力和最终首领要求皆待测试。

## 战潮实验A/B与三世界压力测试（尚未运行）

建议使用相同世界配置和可复现种子进行战潮关闭/开启的两组对比，每组先50局设计评估，再在正式引擎可用后扩大到100/1000局。记录：
- 同种策略的三世界拯救率、平均世界崩溃日与本局时长；
- 战潮出现次数、战报长度、每世界构筑选择次数、玩家主动处理/忽略构筑比例；
- 三人/二人之力使用率、资源援助使用率、无融合完成终局的比例；
- 战潮增加的额外XP/R/D与清剿行为价值，是否挤压探索和拯救；
- 升级强化是否导致玩家每几天就必须打开弹窗，反而破坏挂机；
- 在战潮关闭时，保持现有确定性Boss判定与世界结局规则。

**采纳条件：** 不引入实时手动走位；不产生多份敌人奖励；不使三人之力成为强制通关手段；无玩家干预仍能自动推进；开启后策略依旧有明显取舍。所有百分比、奖励预算和时长阈值仅为实验指标，未经过真实跑局。

## 2026-11-12 · 活跃巢群战斗评分 A/B

本次对候选持续威胁行动评分从 0 到过高数值进行固定种子对照，发现过高权重把首局默认全救率推至100%，不能接受。候选值3.5只在具备战斗实力、巢群外围清剿进度尚未完成时生效，原来“高危时无条件选清巢”的想法已撤回。加入`balance:check`条件：战潮模式默认首局每局平均战潮场次必须介于0.1和5之间，原有的首局全救率不高于98%、无卡局、战潮总加成不超限仍保持。

这里的指标是人工不干预、固定随机种子的**回归烟雾指标**，不是玩家胜率或最优调参。等待真实CI与移动端玩家体验验证。
