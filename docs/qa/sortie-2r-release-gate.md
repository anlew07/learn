## 2R 的产品判断

不加技能树、额外建筑、准备消耗、全新资源或战斗数值。本轮只验证：**新玩家能否自己找到目标 → 选择风险 → 活过出击 → 读懂收益 → 决定存钱或花 6 石 → 在第二场观察到实际成长**。

| 真实流程 | 玩家应自行理解的事实 | 工程证据 | 真人未验证点 |
| --- | --- | --- | --- |
| 首次打开标题菜单并进入营地 | 看懂游戏主题与开始入口；进入营地后理解 75s 目标、自动攻击及两条风险路线 | 新增 2R 首屏/任务手指 E2E；原 2L-C 手指任务流程 | 是否能主动比较两条路线；2R UI #108 已将路线卡排在出击 CTA 之前，但自动化不能证明玩家理解 |
| 险地出击 | 10s 才出现回收点、65s 截止，守卫会增加风险；要到点驻留 1s | 原 2L-C 三屏物理回收、2P 三屏真实时钟 | 是否知道需要主动接近，能否区分「战斗剩余」和「回收截止」 |
| 25s 战技暂停 | 计时确实冻结；雷偏进攻、纹偏保命，只选一个 | 2R 三屏手指选择 + 真实 1500 tick 冻结 | 是否能在没有讲解时做出理由明确的选择 |
| 首战结束 | 3 石基础、碎片可换石；险地目标只有完成且胜利才发 +2 石 | 2L-C 权威双世界日结、已防重领奖 | 玩家是否能区分固定奖励、拾取和任务奖金 |
| 营地投资 | 保留 6 石供后续用，或花 6 石修复永久剑台；花费不可退 | 2Q 三屏真付款与回执、幂等、正式档隔离 | 投资与储蓄是否真正纠结，而非被界面诱导 |
| 第二场 | 灵刃伤害 1 → 2 是权威成长；击退和当场灵石**不是回本证明** | 2Q 真二场、权威伤害验证；2N 真实配对 ROI | 玩家能否感受到变化，是否想再玩一场 |

### 2R 新增自动化

`e2e/sortie-first-session-2r.pw.js` 独立执行，不复写原 2L/2P/2Q 的两场测试。标题菜单由 2S `e2e/sortie-title-menu-2s.pw.js` 覆盖；本文件通过真实触控从标题页进入营地，刷新后也重新经过标题页。

- 首次打开 `/?mode=sortie` 必须先显示标题菜单；320×568、390×844、430×932 竖屏及 844×390、932×430 横屏均已由 2S 自动化覆盖，标题页只提供「开始冒险 / 玩法说明」并保留正式模拟器出口。\n- 从标题菜单通过真实手指触控进入营地；空白隔离档确认目标、25s 暂停说明、险地失败不领奖金、零回执和正式档空白。
- 不使用 `locator.click()`、程序滚动、伪造奖励、快速提交结算；只能用真实坐标 `touchscreen.tap`、CDP 手指滑动和持续摇杆接触完成任务选择及战技抉择。
- 验证点击险地后仅保存选择、不扣灵石、不推进世界日；刷新后仍选险地，主按钮反映选择，另一任务被正确锁定。
- 真正推进 25 秒到 1500 tick 自动暂停，暂停期间时间不动，触摸选择防护技；战斗中断后回营地，不提前发奖、不推进日，正式存档不受影响。
- 留存三屏尺寸的 `first-impression`、`skill-choice`、`interrupted` 截图；先审查最终 CI artifact，再人工判断信息密度，**截图不能替代真人理解**。

现有原 `e2e/sortie-playable-2l.pw.js` 已负责三屏真实 75s × 2、付款、恢复、第二场权威成长，不能为了缩短 CI 而删除。现有 2P 倒计时、2M 导航、2N/2O 固定种子试验仍必须通过。

## 真人盲测合同（目前未执行，不能标记通过）

优先招募 **5 位没有看过项目文档、没有参加开发的玩家**，至少覆盖 Android / iOS 真实触摸设备；实际运行平台为 TapTap WebView 时应再做对应真机。5 人是发现常见可用性问题的**探索性规模**，不产生有统计代表性的用户留存率或商业转化率。

每位玩家给独立空白隔离档，竖屏，观察 3–5 分钟；征得同意再录屏。不解释战技、危险档、资源或剑台数值，不读出按钮名称。只提供非诱导任务：

> 你刚到这个雾谷营地。请试着完成一次外出，看看得到什么，再决定怎样让下一次外出更有把握。想停就停；操作或界面看不懂时直接说出你的想法。

记录每人的**可观察行为**，不要根据事后自述补写“完成了”：

| 观测项 | 记录方式 |
| --- | --- |
| 启动发现 | 进入后到首次主动操作的秒数；有没有发现稳妥/险地是两条路线 |
| 战斗理解 | 是否试着拖摇杆；是否知道自动攻击；是否发现任务点与倒计时 |
| 战技 | 25s 是否知道已经暂停；选择雷或纹前说出的理由、是否误以为可双选 |
| 资源反馈 | 结算后能否指认本场实得灵石、险地额外奖有无生效及原因 |
| 营地选择 | 是否自己找到修剑台入口；买或不买的理由、是否知道消耗 6 石 |
| 第二场变化 | 是否自己判断灵刃确已提升为 2 伤害；是否误以为单场已回本 |
| 玩的动力 | 玩家是否自发选择再出击；用一句话描述最想继续做的事情 |
| 阻碍 | 时间戳、录屏位置、设备/视口、用户原话、复现方法和严重程度 |

### 通过 / 暂缓规则（产品暂定门槛，不是已测结果）

- **技术强制门槛**：2R 最终 SHA 完整 Validate H5 成功，0 个新失败；三尺寸真实触屏测试、原两场回归、权威结算、正式档隔离均通过；截图 artifact 有效且完成复核；Pages 与真机需另外验收。
- **真人理解门槛**：5 人中至少 4 人无需提示完成首次出击、至少 3 人能描述一项真实风险/资源取舍、至少 4 人能指出第二场**已验证的伤害成长**，且至少 3 人愿意自发开始第二次出击。任何一条未满足，先分析设计问题再复测；这只是小样本的初步产品门槛。
- **阻断级问题**：任意设备存在按不到开始/战技/退出、任务误导发奖、重复扣费、正式档污染或数据损失，直接 No-Go；相同重大理解障碍被至少两人独立遇到，先修复后复测。
- **效果门槛**：别把“击退增加”“进了目标点”“看到动画”当成乐趣证据；观察选择前的犹豫、选择后的反馈、是否主动寻求下一场，收集负面结果同样保留。

## 已识别的优先观察风险

1. **路线选择的理解仍待真人验证**：2R UI #108 已把稳妥/险地卡片排在出击 CTA 之前，并增加独立标题菜单；自动化只证明卡片和按钮可见、可触，不证明新玩家理解两条路线的收益、风险与撤离代价。
2. **战斗开始前的信息量偏大**：任务、预算、剑台、图谱、正式档隔离说明连续排列；320 短屏尤其需要盲测「先看什么」。
3. **投资的即时资源回报未证实**：2N 只证明了部分高危生存收益，不要把 2Q 的伤害成长文案宣传成“6 石很快回本”。
4. **实验入口不等于正式入口**：当前 `/?mode=sortie` 仍是隔离试验。2R 通过后，需另行审查 2A→2G 的堆叠 PR 与 `main` 最新差异、安全集成、Pages 实际部署、TapTap 真机/审核；绝不能仅合并本 QA PR 就宣称上线。
