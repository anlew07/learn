## 4. 下一阶段执行顺序

### P0：真人首局盲测
使用非调试入口 `https://anlew07.github.io/learn/`，全新浏览器配置，不清理玩家现有数据。试玩者不得提前阅读玩法文档。按历史基线的六项任务记录：
1. 能否说出本局目标与成功条件。
2. 能否辨认当前风险最高的世界并解释原因。
3. 能否区分分身自动行动与玩家主动决策，并推进一次模拟。
4. 能否修改策略并理解它是长期倾向、是否消耗 AP。
5. 能否找到事件/战斗结果与战报，并完成一次合法跨世界援助。
6. 能否解释结算因果、碎片用途和下一局变化；误认为碎片可直接购买永久属性升级须记为误解。

每项记录独立完成 / 提示后完成 / 未完成、用时、误触、原话、截图或录像。建议门槛仍为每项至少 80% 无提示完成、关键任务无阻断；样本不足时明确标记未验证。

### P1：真机矩阵
至少覆盖 Android Chrome 与 iOS Safari；可用时增加 TapTap WebView。检查 320px 级窄屏、系统字号、刘海/底部安全区、触摸热区、后台恢复、IndexedDB/Web Locks、长时间运行和发热。记录设备型号、系统/浏览器版本、commit、步骤与证据。

### P1：场景品质迭代
目前像素场景属于垂直切片，不能宣称达到《Dungreed》成品表现。后续应围绕真实 RunState 做角色动作帧、环境层次/遮挡、危机与救援状态反馈、战斗命中反馈；每次先做一个可验收切片，不做纯装饰堆量，也不改变引擎结算/RNG。
