## 必须实机完成的观察

1. **点击目标：** 在世界底部、跨世界援助、事件选项和战技三选一上逐个触摸，记录按钮触摸区是否达到44×44 CSS px、是否会被底部导航/手势条遮挡、是否误触邻接控件。
2. **字体与换行：** 375/390 宽系统字体125%、150%，逐页观察较长中文事件、解释、奖励与警告；用截图标记截断、错位、超出屏幕的内容。
3. **弹窗/原生表单：** 打开及取消确认援助、重新开局、闭关，切换来源目标及速度；核对确认/取消真实后果、返回按钮及屏幕键盘。
4. **减少动态效果：** 打开系统“减少动态效果”后重播三波战潮，检查是否停止动画且保留胜负、奖励、回放文本；核对页面是否仍可操作。
5. **后台恢复：** 暂停/切后台1–3分钟并返回，检查停在正确日数，持久化可恢复，二标签写入权未被偷取。
6. **长期稳定性：** 低端设备持续30–60分钟，记录帧率波动（如果可测）、内存/温升/电量、意外退页/刷新、浏览器控制台异常、运行日数与实际日数是否符合速度。
7. **TapTap WebView：** 记录宿主版本与 HTTPS、安全上下文、`navigator.locks`、IndexedDB、顶部/底部遮挡、分享/返回行为；无法获得宿主则保持未执行。

## 自动化回归的保护线

- **已存在且持续运行的测试：** `e2e/mobile-runtime.pw.js`（后台、钟表漂移、多标签接管、基本字号与尺寸）；`e2e/storage-boundaries.pw.js`（事务中止）；`e2e/storage-recovery.pw.js`（读写失败和拒写）；`e2e/pixel-ui.pw.js`（CSS像素风和减少动态）。
- **本轮新增：** `e2e/first-player-acceptance.pw.js` 将第一局操作路径、完整真实引擎结局、事件/战技命令、跳过教学不损失进度、四宽度下关键动作可达性组织为独立接受测试。
- **不可得出的结论：** Chromium/CI 通过不代表手机真实性能、iOS Safari、TapTap WebView、真实用户理解或视觉审美已经通过。
