## 最小反馈改动及观察点

| 玩家时点 | 可观察反馈 | 自动化断言 |
| --- | --- | --- |
| 营地进入前 | 显示坚持 75 秒、自动灵刃、25 秒暂停、碎片 3 换 1 与 2 灵石上限 | 首屏目标、试验档隔离、直接触摸出击 |
| 战斗中 | 固定任务条、剩余秒数与时间进度、伤害/击退/碎片/兑换的短状态提示（根据真实战斗状态变化生成） | HUD 与 Canvas 同屏、反馈触发与真实回执比对、暂停时间冻结 |
| 第 25 秒 | 战技卡标注进攻/防护，倒计时明确冻结；选定后恢复 | tick=1500，等待后仍不推进、两种技能参数、按钮视口坐标可触 |
| 战斗结束 | 结算灵石/经验/准备/碎片做数量分组，双世界各行独立展现，保留原有详细回执 | 回执数额、下一世界日、双世界行数、结算回营按钮完整视口可点 |
| 营地建设、再出击 | 修建花费与灵刃伤害 1→2、下一场 HUD 的实际灵刃 2；不承诺胜率提升 | 实际世界资源 -6、刷新保持、次场实际武器伤害 2、撤离只记一次 |

状态提示不是改变奖惩：击退数、生命值、拾取碎片、兑换灵石均读取现有战斗状态；结果资源与双世界变化均读取现有唯一结算回执。伤害增强只是「机制可见」，**不等于投资回本**；2I-C 已知第 2–6 场成本无法兑现，产品仍需另一条线验证。
