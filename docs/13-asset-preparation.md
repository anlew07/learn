## 为什么这次只多做一个状态图集

目前项目的核心交互围绕世界 P/D、AP、灵魂、世界材料、冷却和伤势，状态图标具有稳定复用价值；角色大动作、场景瓦片和多世界专属道具则会随玩法变化。先放一个不到 3KB 的图集，比提前画几十种不确定道具更可维护。

## 资源接口约定

- 使用简单原生 SVG（整数格网、有限色板、`shape-rendering="crispEdges"`），不增加运行时引擎或图标框架。
- 状态和战技图集按**从左到右，固定每格 16×16** 排列，不依赖文件外的脚本，便于后续使用 CSS `background-position`。
- 如果将来启用状态图集，使用已有 CSS 相对 URL：`url("./assets/status-atlas.svg")`。按 32px 放大后可以用 `background-size: 256px 32px`，第 `i` 个图标的背景位置为 `-32*i px 0`；不要指向 `/src/assets/` 这种绝对路径。
- **不把含义写死在图片中**，真实进度、AP 数量、时间、费用、ARIA 等由 DOM 和引擎提供。
- 随时可整体替换美术文件，不影响存档、数值与战技功能。
- 若某种素材未来不再需要，先不接入，最后清理未引用资源；不要为了利用素材发明玩法。
- Vite 负责 CSS `url()` 资源路径处理（[官方说明](https://vite.dev/guide/assets)）；`image-rendering: pixelated` 是渲染提示，不保证非整数缩放在所有 DPR 下每格等宽（[MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/image-rendering)）。
