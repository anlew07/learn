# 像素美术语法 v1 · 三世界共用

> 2026-11-16；衔接 PR #51。主参考《贪婪地牢》，辅参考《Shattered Pixel Dungeon》。只研究轮廓、材质、层次和 UI 规则，不复制具体图像。

## 视觉验收的优先级

1. 玩家、救援同伴、怪物、遗迹/设施从 1× 手机截图就能分清；先看剪影与装备，再看微小纹理。
2. 固定 HUD、世界切换、卡片、事件抽屉、日志、战报和旧详细页共用一套石/木材质、边框和按压态，不出现科技网页控件。
3. 三世界必须在 **形态** 上区分，而不是仅更换色相：灵灾石门/符文；废土断楼/金属废墟；兽潮木栅/山石/犄角。
4. 任何场景效果只能展示现存 RunState，不虚构建筑或奖励，不影响模拟、资源、随机数和存档。

统一 HUD 材质令牌均在 src/pixel-visual-language.css；沿用项目既有自然色系。以下 13 个基础色用于 HUD、按钮、卡片和抽屉，不为每个控件零散创色。

场景环境允许世界专属材质色，始终保持前景/中景/远景明度可分；避免霓虹、模糊、玻璃拟态与软投影。Canvas 采用 320 逻辑像素宽、整数坐标、禁用平滑；所有 SVG 精灵保持 crispEdges。中文使用系统字库保障高密度屏幕的可读性，不勉强使用模糊的微小中文像素字。

## 组件语法（可复用）

- **边框**：2–3px 硬线，左上亮边、右下暗边，外侧仅整数偏移的纯色投影；所有圆角为 0。
- **按钮**：标准浮雕按压态，主操作为浅绿，危险为赤陶橙红；颜色不是唯一的状态线索，仍保留文字、形状和aria标注。
- **卡片/抽屉**：内凹石板 + 浅金外线。详尽的旧档案、事件按钮、战报也继承同一材料体系。
- **HUD**：小地图上叠加紧凑状态牌；救援条与危机条有不同颜色和数值。世界按钮以文字、百分数及高对比选中框区分。
- **图标**：16×16 原创本地图集 hud-symbols.svg，共六枚（策略、事件、援助、队伍、战报、帮助），文字与图标同时显示；不用 emoji 冒充像素美术。
- **移动端**：320px 宽仍看到场景和主要操作；主屏不滚动，详细抽屉内部可滚动；保留安全区、键盘焦点、减少动画设置。

## 资源结构与命名

项目自有资源集中在 src/assets/original/。文件名全部 lowercase-kebab-case，以角色/世界语义命名；角色常用 48×64、怪物 56×60，HUD 图标 16×16。未来瓦片优先 8px / 16px 逻辑网格，避免任意高缩放的模糊边。

本轮新增 5 个 SVG：hud-symbols.svg、wasteland-runner.svg、dust-crawler.svg、beast-warden.svg、horned-hunter.svg；新增 src/ui/pixel-biomes.js 绘制原创环境。保留 PR #51 的 4 张角色/道具原创图；本轮**没有删除其他资源**。已被否决的 Tiny Dungeon / sgravoquest-assets 不得重新引入。

## 素材与许可证调查

- Kenney Pixel UI Pack：<https://kenney.nl/assets/pixel-ui-pack>，官方 CC0，约 750 项 UI 素材。可作后续材质参考，但不能未经风格审阅混搭。本次没有下载或打包。
- 0x72 DungeonTileset II：<https://0x72.itch.io/dungeontileset-ii>，官方 CC0；16px 角色辨识度及透视与现有主体尺寸不完全一致，本轮没有引入。
- Shattered Pixel Dungeon：<https://github.com/00-evan/shattered-pixel-dungeon>，开源 GPL-3.0；仅视觉研究，未直接复用代码/角色/贴图，以避免误用许可证。
- 《贪婪地牢》：仅作画面结构、辨识度、操作反馈参考；未复制游戏画面或具体素材。

**本轮全部新增美术和绘制代码均为项目内原创，第三方包体增量为 0。** 如以后实际引入第三方素材，必须在本文件记录官方来源、许可、版本、文件名、变更和署名要求。

## 验收与不足

- 单测：tests/stage-pixel-art.test.js 保护 8 张图像本地可用性与像素轮廓；tests/pixel-biomes.test.js 检查世界标志差异、危机绘制和纯展示边界。
- 浏览器：e2e/pixel-biomes.pw.js 为三世界分别输出 390×844 视口截图至 test-results/camp-ui；原有多尺寸固定 HUD / 新手事件 / 存档回归继续适用。
- 截图和 CI 必须从 PR 最新提交获取；自动化的像素差异**不等于**真人确认角色可辨识。Android、iOS、TapTap WebView 仍待真机验收。
- 距《贪婪地牢》的差距仍在：角色多朝向与逐帧动画、怪物受击反馈、地块遮挡与镜头运动、丰富的场景物件变体、真实经营反馈对应的地图变化。当前定位仍是可玩的场景垂直切片，不宣称已达到完整商业美术品质。
