# 04 · 万我同源：跨世界系统（架构权威文档）

**适配实例及完整验收：** [双世界联动内容包01](../content/packages/soul-link/01-dual-world.md)。本文记录通用合同；世界具体效果、故事和测试数据放内容包。

各世界独立。跨世界交互只能由 SoulLinkSystem 验证并提交，不直接改变对方的世界专属属性。每个主动指令必须有 operationId，费用、目标变化、冷却与后续状态一次性提交。

## 被动记忆

分身首次重大突破、首次精英胜利或明确标记的特别经历可产生记忆候选；普通挂机收益不广播。

- 来源处于 running，且至少存在一个 running 的其他世界时才成功广播；其他世界当日日常结算完成后发放。
- 每来源每局最多成功广播3次、成功广播之间至少隔5个完整游戏日；已共享的 memoryKey 不重复发。
- 双世界样板：接收方 XP+5（数值暂定）。由共享经验产生的升级**不递归广播**，不回溯改变本日已经结算的战斗。
- 同来源同一日多个候选优先级：重大突破 > 首次精英胜利 > 特殊探索，再按稳定内容 ID；冷却或缺接收者导致的候选不排无限长队。

## 资源援助

主动消费来源世界 R4、可用 AP1、灵魂强度1，目标选择 **P+12 或 D-12**（数值暂定，P/D限幅0–100）。这是跨世界灵魂共鸣转换，不是把灵石直接当作尸潮零件；目标专属资源不会因此增加。

来源、目标必须是两个不同的 running 世界，且资源、AP、魂力足够；主动扣魂后必须至少剩1。闭关分身可以作为资源援助的**来源**，但不代表能够借出战斗力量。援助不占来源世界每日主要行动；可能打破来源的终局资源预留，UI要明确提示。

**冷却每目标统一计算，不分P援助和D援助：** 成功援助第t日后，经过8个完整日，于第t+9日才可再援助同一目标。此规则取代旧的按援助类型分别冷却草案，防止交替灌注作弊。

P援助跨主线阈值时即时补足非随机里程碑；不附送主要行动或最终挑战。援助状态变化即时生效，最终行动依玩家明确指令或正常日终自主检查执行。

紧急救援曾有 AP2/魂2/D-20 的备选设想，**本内容包不启用**，以免与普通 D援助、世界专属防线大修混淆。后续需要时先评审与测试。

## 二人之力和三人之力

一次性对**指定的重大或终局战斗**提供有效等级修正，不是持续3日的战斗 Buff。

| 规则 | 二人之力 | 三人之力（后续解锁） |
| --- | --- | --- |
| 参与 | 承载者+1名合格提供者 | 承载者+2名合格提供者 |
| 本次战斗 | 有效等级+1 | 有效等级+2 |
| 费用暂定 | AP1、魂力1 | AP2、魂力2 |
| 来源条件 | running，实际Lv≥2，不在闭关 | 同左 |
| 全局共用冷却 | 12个完整游戏日 | 20个完整游戏日 |
| 提供者代价 | 后3个全局游戏日可缩放自动XP/R正收益-30% | 两个提供者各承受 |
| 费用合并 | 替代本次重大事件普通人工AP收费，不重复扣 | 同左 |

第 t 日二人之力后，第 t+13 日才可再次发动（无论切换哪种融合方式都要检查同一个全局冷却字段）。三人之力同理第 t+21 日。

有效等级不能绕过**实际成长等级、剧情里程碑、材料与存活状态**。同一次战斗的世界内强化与灵魂叠加互斥。若借力后仍无法胜利，则拒绝，不扣费用。强行出关是**另一项操作**，先结算惩罚，再重新判断能否提供力量。

虚弱从借力的**下一游戏日**开始，持续三个全局日结算；不降低实际/有效战斗等级，不修改自然恶化、威胁压力和固定剧情奖励。其是否需要额外衰减某些专属收益由内容包明确，基础样板暂只衰减可缩放XP/资源收益。

**适配现有双世界：** 灵灾狼王可借尸潮力量；尸潮停车场暴走体与母巢守卫可借灵灾力量；灵灾普通灵脉封印不需要战斗，不能借力替代材料或金丹要求。

## 世界回响

一个世界成功拯救时只生成一枚对应回响；已 saved/failed 的世界不能再正常援助/借力。

- 灵灾回响：目标世界 D-10（暂定）。
- 尸潮回响：目标世界专属资源 +6（暂定）。
- 兽潮回响：目标世界 XP+8（暂定）。

回响免费一次，目标仍需 running，使用后标记已消耗；不能把回响当作已拯救分身重新加入融合。来源/目标终止及重复读档必须安全。

## 数据及测试

全局保存每来源广播限额、记忆 ID、上次广播日、按目标援助冷却、融合共用冷却、operationId/结算状态、回响；世界状态保存提供者未来3日虚弱。所有跨世界指令先整体检验，再一次提交。详细测试见[双世界联动包](../content/packages/soul-link/01-dual-world.md)。

**数值与平衡均未做程序验证**；只将幂等、世界资格、费用不重复、非随机基础拯救路径等作为设计约束。

## 三世界联动内容包

第三局解锁第三世界和三人之力，详情及24项设计验收见[三世界联动内容包01](../content/packages/soul-link/02-three-world.md)。

三人之力必须拥有三个当前running分身，承载者合法战斗、另两名提供者实际Lv≥2且未闭关；一次指定战斗有效Lv+2，暂定AP2/魂2、双方来源后3个全局日可缩放行动收益-30%，共用融合全局20完整日冷却。若三世界已有一个saved/failed，只能按合法条件使用二人之力。已结束世界不重新参与，原先生成的回响仍按一次性规则使用。

幸存者式战潮属于**可开关实验提案**，它对同一个精英/终局战斗仅能触发一次融合，不能将三波演出变成三次收费战斗。见[战潮模拟实验包](../content/packages/combat/01-survivor-waves.md)。
