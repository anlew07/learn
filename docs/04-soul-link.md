# 04 · 万我同源：跨世界系统

所有分身属于同一灵魂，但世界各自独立。跨世界不直接混用境界、职业或世界资源格式。

## 记忆共享（被动）

突破、第一次击败重要强敌、关键探索等重大经历可广播给其他仍运行世界，给予少量通用成长经验或事件定义的感悟。默认每来源世界每局最多分享 3 次，间隔至少 5 游戏日；同一经历只广播一次。**共享经验引起的升级禁止二次广播**，避免循环。广播集中在日终各世界普通行动结束后，不改变当日已结算的战斗。

## 资源援助（主动）

来源世界与目标世界均在运行，来源有足够资源，目标类型可接受对应转换。基准：来源 R-4，AP-1，灵魂-1；目标 P+12 **或** D-12；同目标同援助类型冷却 8 日。方向性加成属于内容配置，不在引擎硬编码。主动消耗灵魂后必须至少剩余 1。

紧急救援：暂定 AP-2、灵魂-2、目标 D-20，每世界最多一次。实际效果与成本待测试。

## 二人之力、三人之力（主动战斗叠加）

**最新统一规则：作用于单次重大战斗，不是持续三天的战斗 Buff。**

| | 二人之力 | 三人之力 |
| --- | --- | --- |
| 参与者 | 承载者 +1 提供者 | 承载者 +2 提供者 |
| 有效战斗等级 | +1 | +2 |
| 代价 | AP1、灵魂1 | AP2、灵魂2 |
| 来源虚弱 | 后续 3 次日终发展收益 -30% | 两名来源各 -30% |
| 共用全局冷却 | 12 个完整游戏日 | 20 个完整游戏日 |
| 资格 | 活跃分身、提供者 Lv≥2、不在闭关、未处于禁止借力状态 | 同左、三人参与 |

有效战斗等级仅用于当前战斗，**不永久提升分身等级，也不绕过终局基础等级/主线/材料**。叠加费用替代该次重大事件战斗的普通 AP 干预费用，不能重复扣 AP。

冷却共用一份记录，切换两种模式不能绕过。世界结束后普通分身不再作为参与者。已有“世界回响”是另一种一次性能力，不等于继续派出已拯救分身。

## 世界回响

世界拯救成功时仅生成一次回响，用于另一个仍运行的世界；消耗后标记已使用。暂定效果：
- 灵灾回响：目标毁灭 -10。
- 尸潮回响：目标资源 +6。
- 兽潮回响：目标成长经验 +8。

最终数值在实际平衡测试后调整。

## 三世界情境

灵灾闭关、尸潮毁灭 85%、兽潮终战 Lv3 对 Lv5 时，三人叠加因灵灾闭关而不可用。玩家可先支援尸潮、强行出关（另有代价）或等待。系统要能正确扣费、给出拒绝原因，并始终保留其他世界自主发展。
